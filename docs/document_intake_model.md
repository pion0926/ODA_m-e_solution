# 자료 일괄등록 데이터 모델

## 처리 원칙

자료는 `원본 보존 → 텍스트 추출 → 메타데이터 정형화 → 전문가 규칙 평가 → LLM 교차검토 → 사람 확정 → 평가 갱신` 순서로 처리한다. LLM 결과만으로 슬롯을 확정하지 않으며, 적용한 규칙 버전과 판단 근거를 함께 저장한다.

## 문서 저장 구조

각 문서 메타 JSON은 다음 네 영역으로 구성한다.

- 원본 정보: `id`, `fileName`, `mimeType`, `size`, `rawPath`, `uploadedAt`
- 추출 정보: `textPath`, `textPreview`, `extractionMethod`
- 분석 정보: `analysisMetadata`
- 배정 정보: `criterionId`, `evidenceName`, `matchStatus`, `allocationTrace`

`analysisMetadata`의 기본 필드는 다음과 같다.

| 필드 | 용도 |
|---|---|
| `documentType` | 보고서·조사자료·회의록·행정자료 등 자료 유형 |
| `title` | 문서의 공식 명칭 |
| `period` | 기준일 또는 대상 기간 |
| `region` | 파푸아 사업지역 또는 전체 |
| `organization` | 생산·승인·책임기관 |
| `dataLevel` | 개인·시설·지역·사업 전체 등 집계 수준 |
| `disaggregation` | 성별·연령·지역·취약집단 분리 기준 |
| `indicators` | 문서가 측정하거나 설명하는 성과지표 |
| `summary` | 사실 중심 핵심 요약 |
| `qualityFlags` | 결측·중복·불일치·산식·출처 문제 |
| `language` | 문서 언어 |
| `confidentiality` | 개인정보 및 민감정보 수준 |

운영 전문가는 화면의 **분석·배정 기준**에서 항목의 표시명, 추출 설명, 예시, 필수 여부를 변경할 수 있다. 저장된 실제 설정은 `data/document_intake_rules.json`에 기록된다.

## 슬롯 의미 판정

1. 전문가는 슬롯마다 자연어로 `배정 기준`, `배정하지 않는 조건`, `대표 자료 예시`를 작성한다.
2. LLM은 파일명 단어가 아니라 문서 본문, 추출 메타데이터, 슬롯의 평가 활용 목적을 비교한다.
3. LLM은 최대 4개 후보에 대해 신뢰도, 구체적인 문서 근거, 반대 근거를 반환한다.
4. 1순위가 자동확정 기준 이상이고 2순위와의 차이가 최소 점수 차 이상일 때만 자동 배정한다.
5. 그 외 자료 또는 AI를 사용할 수 없는 자료는 자동 배정하지 않고 전문가 확인 대기로 보낸다.

기본 자동확정 기준은 82%, 후보 간 최소 점수 차는 12%p다. 이 값은 화면에서 수정할 수 있다.

## 추적성

`allocationTrace`에는 규칙 버전, 결정 상태, 최종 후보, 대안 후보, 신뢰도, 후보 간 점수 차, 문서 근거, 반대 근거 및 검토 사유가 저장된다. 따라서 기준이 변경된 뒤에도 과거 자료가 어떤 판단으로 분류됐는지 재현할 수 있다.
