# 평가보고서 섹션별 작성 설정

## 운영 흐름

27개 보고서 섹션은 각각 독립된 작성 설정을 가진다. 담당자는 보고서 에디터의 **섹션 작성 설정**에서 다음 내용을 수정한다.

- 섹션 작성 목적
- 기본 생성 프롬프트
- 담당자 추가 지침
- 해당 섹션에서만 참고할 업로드 자료

설정은 `data/report_section_settings.json`에 버전과 함께 저장되며 다음 생성 요청부터 적용된다. 원본 코드 프롬프트는 `basePrompt`로 유지되므로 담당자 설정과 원본을 구분할 수 있다.

## 참고자료 적용

담당자가 자료를 직접 선택하지 않은 섹션은 기존 DAC 기준·증빙 슬롯 연결을 사용한다. 한 개 이상의 자료를 직접 선택하면 그 목록을 해당 섹션의 전용 참고 코퍼스로 사용한다. 자료 선택은 파일명이나 경로가 아니라 문서 ID로 저장되어 동명 파일을 구분한다.

## 섹션 단독 생성

**이 섹션만 생성** 요청은 현재 선택한 `partId` 하나만 생성 엔진에 전달한다. 생성 결과는 동일한 `sectionId`에 병합하며 다른 26개 섹션의 저장 내용은 유지한다. 프롬프트나 참고자료 설정이 변경되면 섹션별 fingerprint도 변경되어 생성 근거를 추적할 수 있다.

## 저장 데이터

```json
{
  "version": 2,
  "sections": {
    "criteria-effectiveness": {
      "description": "효과성 분석의 목적",
      "prompt": "기본 생성 프롬프트",
      "additionalInstructions": "담당자 추가 지침",
      "customReferenceDocumentIds": ["document-id"]
    }
  }
}
```
