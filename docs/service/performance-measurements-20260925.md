# 성과지표 측정값 미추출과 작업 트레이 수정

운영 knut의 2026-09-24 16:24 UTC 분석은 문서 22건/35개 조합을 읽었지만
observations를 모두 빈 배열로 저장했다. 지표 14개 중 연결 자료가 있는 지표도
측정값이 없었으며, 빈 배열이 증분 분석의 완료 이력에 들어가 재검토에서 제외됐다.

사용자가 승인한 `5차년도 지표별 실적 현황` 원문 1,438자를 현재 연결 모델
`google/gemini-3.5-flash-lite`로 재현했다. 기존 요청은 빈 배열을 반환했다.
이유 확인 응답은 `CPCR 강사 양성여부(명)`와 PDM 강사 인원 지표의 정의·단위가
불일치한다고 판단했다. 원문에는 목표 10명, 실적 6명이 명시되어 있다.

수정 요청은 동일한 측정 대상·활동·범위·단위의 표현 차이를 허용하고, 표 머리글의
목표/실적을 구별한다. 검증수단 목록과 다른 종류의 문서라는 이유만으로 공식 보고
수치를 버리지 않는다. 인원/횟수/가동률/출판·배포 등 서로 다른 개념의 변환은 금지한다.
모든 지표에 구조화된 검토 이유를 요구하고 원문 수치 검증은 유지한다.

동일 원문·동일 모델의 수정 요청에서 목표 10명, 실적 6명의 원문 인용과 지표 연결이
정상 추출됐다. 검증 실행은 평가 결과나 문서 캐시를 변경하지 않았다.

기존 실제 측정값은 유지한다. 검토 이유가 없는 이전 빈 결과만 다시 분석 대상으로
노출하고, 새 정책에서 검토한 수치 미확인 결과는 이유와 함께 저장해 반복하지 않는다.
AI가 수치를 제시했으나 검증되지 않은 조합은 완료 이력으로 기록하지 않는다.

AI 작업 트레이는 진행/대기 작업이 있으면 자동으로 열리며 작업 중 닫기 버튼을 숨긴다.
보고서 개별 섹션·발표자료·내보내기 상태도 본문 없는 프로젝트별 상태 API로 복원한다.
