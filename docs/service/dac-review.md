# DAC 평가 준비와 질문별 원문 검토

DAC 버튼은 평가 준비 창을 연다. GET /api/v2/evaluations/analysis-plan은 기존 요약, DAC 슬롯 매핑, 기준 문서, 추출 원문으로 11개 질문의 문서와 검토 구간을 제안한다. 미리보기에서는 AI 호출이나 점수 산정을 하지 않는다.

기존 매핑은 DAC 기준 단위이므로 해당 기준의 질문별 후보로 사용한다. 기준 문서는 계획·목표 대조용이다. 질문·증빙 요건·저장된 매핑 근거와 원문 발췌를 검색하여 주변 맥락을 포함한 최대 3개 구간을 추천한다. 검색이 부족하면 첫 구간을 제안한다. 이는 의미 검색의 완전성을 보장하지 않으므로 화면에 원문 범위와 한계를 표시하고 전체 본문 검토 선택을 제공한다. 산출물 내용으로 제작·배포·교육 효과를 확정하지 않는다.

사용자는 질문별 문서를 추가·해제하거나 새 문서를 업로드할 수 있다. 기본 분석이 끝나야 평가할 수 있다. 전체 본문 선택은 해당 질문의 선택 문서에만 적용되며 원본에서 전문을 다시 추출한다. 이전에 확정한 문서 선택은 다음 계획에 유지하고 신규 문서는 업로드 매핑을 반영한다. 기준 문서 교체 시 과거 선택은 초기화한다.

POST /api/v2/evaluations에는 revision, mappings, full_questions가 필요하다. 서버에서 재구성한 계획으로 원문 범위를 확정하며 클라이언트는 임의의 원문·범위를 제출할 수 없다. 외부 프로젝트 문서, 중복 문서, 오래된 계획은 거부한다. 확정 계획은 evaluation_runs.input_snapshot.review_plan에 보존한다.

실제 평가에서는 선택된 문서·질문·구간만 근거 추출 대상으로 전달한다. 선택 범위를 평가 캐시 키에 포함하고, 기존 점수 규칙과 원문 인용 검증을 유지한다. 전체 사업개요는 기존 등록 정보에서 생성하고 PDM은 저장된 상태를 참고한다. 질문별 근거 부족은 판정 보류 대상이며, 기존 점수 유지·상향을 강제하지 않는다.

검증: tests/test_dac_review.py, test_dac_fulltext.py, test_dac_rules.py 및 tools/qa_dac_review.py. 통합 테스트는 격리 DB와 Chromium에서 실제 API/UI를 연결하고 외부 AI만 모의 처리한다.
