# 프로젝트별 AI 모델 배정 — 개발 서버

반영일: 2026-09-13. 개발 환경 `http://127.0.0.1:8002`에만 적용함. 운영 `:8000` 및 V1.0.0 릴리스 이미지는 변경하지 않음.

## 사용 방법

1. 개발 서버에 관리자로 로그인함.
2. **프로젝트 관리 → 해당 프로젝트 → AI 모델 배정 · 가격 비교**를 선택함.
3. Gemini / GPT / Claude 필터로 모델과 입력·출력 단가를 비교함.
4. 모델을 선택하고 **프로젝트에 모델 배정**을 누름.
5. 해당 프로젝트 사용자의 다음 문서 분석·재평가·보고서 생성부터 선택한 모델을 사용함.

배정 변경은 기존 분석이나 보고서를 자동으로 덮어쓰지 않음. 새 모델로 기존 자료를 다시 판단하려면 재평가 후 보고서 재생성을 실행함. 업로드 문서는 대기·재요청 후 실제 실행을 시작할 때 최신 프로젝트 연결 모델을 조회하며, 실행 중에는 해당 모델을 유지함. 평가·보고서 작업은 접수 당시의 모델을 유지함. 사용자 계정에서 관리자 설정을 덮어쓸 수 없음.

문서 작업 트레이에서 대기·분석·재시도·AI 연결 대기 문서를 중지할 수 있다. 대기는 즉시 중지되며 실행 중에는 중지 요청을 기록하고 현재 외부 요청의 응답을 기다린다. 단계별 검사와 실행 식별자로 중지된 실행의 후속 요청·결과 저장을 차단한다. 중지 완료·실패·연결 대기 문서는 재요청할 수 있고, 재요청은 실행 당시의 최신 연결 모델을 사용한다. 원본과 추출 텍스트는 보존한다.

기존 프로젝트에는 서버 기본 모델을 초기 배정하였으며, 신규 프로젝트도 서버 기본 모델로 시작함. 관리자가 프로젝트별로 변경할 수 있음. 현재 기본값은 Gemini 3.5 Flash Lite임. 비싼 최신 모델로 자동 전환하지 않음.

## 선택지와 가격

현재 검토된 선택지는 12개임. 아래는 확인 당시 OpenRouter 표준 텍스트 단가이며 **USD / 100만 토큰** 기준임.

| 공급사 | 모델 | 입력 | 출력 |
|---|---|---:|---:|
| Google | Gemini 3.8 Flash | 0.75 | 3.75 |
| Google | Gemini 3.1 Pro Preview | 2 | 12 |
| Google | Gemini 3.5 Flash Lite | 0.30 | 2.50 |
| OpenAI | GPT-6 Astra | 10 | 50 |
| OpenAI | GPT-5.6 Sol | 2 | 10 |
| OpenAI | GPT-5.6 Terra | 2 | 12 |
| OpenAI | GPT-5.6 Luna | 0.20 | 1.20 |
| Anthropic | Claude Fable 5.1 | 10 | 50 |
| Anthropic | Claude Opus 5 | 5 | 25 |
| Anthropic | Claude Sonnet 5 | 2 | 10 |
| Anthropic | Claude Haiku 4.5 | 1 | 5 |
| Anthropic | Claude Opus 4.8 — 기존 작업 호환 | 5 | 25 |

실제 연결 방식은 기존 **OpenRouter API 경유**를 유지함. 공급사별 직접 API 키 입력 기능을 새로 만든 것은 아님. 따라서 화면은 [OpenRouter 모델 목록](https://openrouter.ai/api/v1/models)의 실제 경로 가격을 사용하며, 공급사의 직접 API 가격과 차이가 있을 수 있음.

공식 비교 출처: [Google](https://ai.google.dev/gemini-api/docs/pricing), [OpenAI](https://developers.openai.com/api/docs/pricing), [Anthropic](https://platform.claude.com/docs/en/about-claude/pricing). OpenAI Docs 및 각 공급사 공식 자료에서 현재 모델을 확인한 뒤 OpenRouter의 실제 제공 ID와 대조함.

- 화면에 가격 확인 시각과 통화·단위를 표시함. 카탈로그는 프로세스 내 최대 1시간 캐시하며 수동 갱신 가능함(연속 갱신은 15초 제한).
- 조회 실패 시 이전 참고 가격임을 표시하고 신규 배정을 차단함. 기존 배정/작업은 지우지 않음. 미제공 모델이나 확인 불가 가격을 0원으로 표시하지 않음.
- 예시 입력·출력 토큰을 넣으면 1회 요청의 참고 비용을 계산함. 긴 문맥 단가 구간도 반영함.
- 실제 비용은 추론 토큰, 캐시, 긴 문맥, 도구, 공급 경로, 세금·충전 수수료 등에 따라 달라짐. 보고서 1건의 총비용이나 구독료가 아님. 보고서 생성은 여러 요청과 품질 검토·재시도를 포함함.

## 코드 구분

| 파일/영역 | 책임 |
|---|---|
| `redesign/backend/kodame_intake/model_catalog.json` | 검토된 모델 ID·설명·기능 차이·장애 시 참고 가격 |
| `model_catalog.py` | 공개 카탈로그 조회, 가격 변환, 제공 여부, 요청 옵션 호환 처리 |
| `project_ai.py` | 프로젝트 정책 조회·배정, 동시 수정 충돌 방지, 변경 이력 |
| `llm_models.py` | 허용 모델 검증과 요청/작업 단위 모델 컨텍스트 |
| `db.py` | 프로젝트 모델·revision·수정 시각 및 `project_ai_changes` 이력 테이블 |
| `main.py`, `worker.py` | 로그인 프로젝트 해석, 작업 시작 시 모델 고정, 계정별 변경 차단 |
| `assets/project-ai-ui.js`, `.css` | 관리자 모델·가격 비교 화면 |

추가 모델은 JSON에 무작정 ID만 넣지 말고 공식 API 및 OpenRouter의 ID, JSON 응답·이미지 입력 지원, 요청 옵션을 확인한 뒤 테스트해야 함. 모델 목록 수정은 개발 이미지 재빌드 필요. 단가·제공 상태는 공개 API에서 갱신함. `OPENROUTER_PRESENTATION_MODEL`은 개발 경로의 선택 우선순위에서 제외되며, 발표자료도 프로젝트 정책을 사용함.

### 실제 적용 경로

관리자 프로젝트 배정 → DB 정책 → 로그인 프로젝트 → 요청 시 모델 스냅샷 → 문서 큐/평가/보고서 작업 → 공통 요청 옵션 호환 처리 → OpenRouter.

- 문서 분석, 후속 사업개요 작성, PDM 근거 추출/리스크 분석, DAC 근거·평가, 27개 보고서 섹션 생성·수정에 적용함.
- 발표자료 생성, 변화이론 도식 생성 및 화면 번역도 같은 정책을 사용함.
- 병렬 처리에서 프로젝트·계정·모델 컨텍스트를 복사함.
- PDM 근거, DAC 근거, 화면 번역, 변화이론 캐시는 모델을 구분함.
- HWPX 고정 양식/한컴 호환 변환 코드는 변경하지 않음. AI 생성 내용과 고정 문서 변환 단계를 유지함.
- 공급사 간 임의 모델 대체를 하지 않음. 모델이 실패하면 오류를 표시하고 관리자 설정을 유지함.

### API

- `GET /api/v2/admin/ai-models[?refresh=true]`: 관리자 모델·가격 목록.
- `PUT /api/v2/admin/projects/{id}/ai-model`: `llm_model`, `expected_revision` 필수. 관리자 전용.
- `GET /api/v2/account/settings`: 해당 사용자의 선택 프로젝트 모델을 읽기 전용 반환.
- `PUT /api/v2/account/settings`: 계정 단위 모델 변경은 403 차단.

## 검증 결과와 한계

- 새 정책 관련 테스트 25개 및 기존 모델 컨텍스트 테스트 3개 통과.
- 전체 백엔드: **370 passed / 11 failed / 61 subtests passed**. 11개는 변경 전 V1.0.0 소스를 별도 컨테이너에서 검사해 모두 동일하게 재현함. 삭제된 수동 본문 편집기·루트 index 파일·과거 고정 문구/버전/샘플 계정 생성 코드를 요구하는 오래된 `test_frontend_v1_shell.py` 검사임. 이번 변경을 통과시키기 위해 해당 검사를 삭제하거나 제품 코드를 과거로 되돌리지 않음.
- 프런트엔드 계약 검사 9개 스크립트 모두 통과.
- 실제 브라우저: 관리자 프로젝트별 버튼, 3개 공급사 필터, 12개 가격, 라디오 선택/저장, 재접속 후 유지, 다른 프로젝트 불변, 긴 문맥 가격 계산 확인.
- 실제 API: Gemini 3.8 Flash, GPT-6 Astra, Claude Fable 5.1 각각 분석·보고서 클라이언트 1회씩 총 6회, 요청 모델과 응답 모델 일치 및 JSON 결과 확인. 합성 교육 실적만 사용함. 총 1,042 토큰, OpenRouter 응답 cost 합계 USD 0.010988. 세금·충전 수수료 제외.
- QA 전용 빈 프로젝트 2개를 유지함. 검증 계정은 종료 후 비활성화함. 기존 사업 문서 437개 유지, 기존 보고서 재생성/덮어쓰기 없음.
- 12개 모델 모두의 27개 섹션 전체 재생성 또는 모든 한컴 버전의 문서 열기 시험을 이번 작업에서 다시 수행한 것은 아님. HWPX 관련 회귀 테스트는 통과했으며 원본 양식 파일은 유지함.

상세 실제 응답은 로컬 `docs/qa/reports/FT-20260913-project-ai-probe.json`에 기록함. 고객 데이터 보호 정책에 따라 생성된 QA 결과물은 Git 추적 대상에서 제외함.

## 배포/복구

개발 API·작업자·웹만 빌드/교체함. 운영 5개 컨테이너의 ID·이미지가 작업 전후 동일함을 확인함. 개발 DB 변경 전 백업: `.runtime/backups/project-ai-before-20260913.dump`.

DB 변경은 컬럼/이력 테이블 추가 중심이며 기존 데이터 삭제 없음. 문제가 생기면 개발의 이전 이미지로 복구하고 원인을 확인함. 운영 반영은 별도 릴리스 절차로 수행하며, 이 작업에서는 Git push나 운영 배포를 하지 않음.
