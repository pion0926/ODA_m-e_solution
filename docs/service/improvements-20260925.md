## 잔여 위험

1. **AI 의미 판단**: 합성 정답 세트는 제한적이다. 후보 범위 밖에만 있는 반대 근거는 처음부터 전체 검토를 선택하지 않으면 놓칠 수 있다. 무검출/상충 확대가 모든 누락을 제거하지는 않는다. 제출 전 사람의 출처·결론 검토를 유지한다.
2. **이미지 보안**: 오프라인 Trivy에서 Debian OS 759건 중 HIGH/CRITICAL 121건을 탐지했고 검사 DB에 고정 버전이 없었다. 설치 버전 기준이며 실제 악용 경로를 모두 확인한 건수는 아니다. Python 도구 쪽 HIGH 2건은 pip 내부 msgpack과 빌드 SBOM의 setuptools이며, setuptools는 실행 환경에 설치되어 있지 않음을 별도 확인했다. 직접 requirements pip-audit는 0건이다. 전체 이미지 취약점 0건/외부 침투검사 완료로 표현하지 않는다.
3. **호스트 장애**: 로컬 암호화 백업과 DPAPI 키가 같은 PC/사용자에 종속된다. 오프호스트 제외로 PC/계정 동시 손실 대비 복구는 갖추지 않았다.
4. **성능·출력 범위**: 수십 프로젝트·대형 스캔/OCR 장시간 부하·네트워크 분할·한글 데스크톱 인쇄·모든 15/30쪽 발표자료는 이번에 실측하지 않았다.
5. **기존 결과**: 새 정책/프롬프트 지문은 기존 결과를 자동 재분석하거나 최신 승인으로 바꾸지 않는다. 재검토 필요 표시를 유지한다.
6. **경고**: Starlette TestClient/AnyIO deprecation 2건, QA 미리보기 출처 불명 MutationObserver 콘솔 경고를 관찰했다. 화면/출력은 동작했으나 콘솔 무오류로 보고하지 않는다.

Docker Scout 검사는 비공개 이미지 정보 외부 전송 우려로 자동 승인 검토가 차단하여 실행하지 않았다.
공개 취약점 DB만 받은 후 네트워크 없는 로컬 Trivy로 대체했다. 비공개 이미지를 외부 검사 서비스에 업로드하지 않았다.
