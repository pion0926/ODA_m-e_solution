# HWPX 길이 초과 복구

- 이름을 포함하는 `- [1-2 지표명]: 성과지표: ...` 레코드를 인식하지 못해 지표들이 한 셀로 합쳐지던 원인 수정. 실제 실패 자료는 12개 지표로 분리된다.
- 성과지표, PDM, 평가매트릭스, 사업개요 병합 그룹, 환류과제·교훈에서 측정 높이를 초과하면 큰 셀부터 상세 본문으로 이동한다. 표에는 원문 앞부분과 고유 연결 번호를 남긴다.
- 상세 본문은 문자열을 요약하거나 자르지 않고 명시적 페이지로 이어진다. Unicode·XML 특수문자, 줄바꿈을 보존하고 연결 대상도 검증한다.
- 반복 머리행·병합 셀·글자 크기·표 높이 검증을 유지한다. 비텍스트 개체나 잘못된 표 구조를 무조건 성공 처리하지 않는다.
- 현재 작성 규약의 환류과제 열(후속조치, 책임주체, 관찰·근거) 인식도 보완했다.
- 123개 관련 테스트 통과. `tools/qa_hwpx_overflow.py`로 실패 프로젝트의 저장 자료를 읽어 로컬 후보를 생성하고 XML/조판 계약/의미 매핑/목차 검색 및 kordoc·rHWP 렌더링 확인. AI 호출, 보고서 DB 갱신 없이 수행한다. 렌더러별 페이지 수는 다를 수 있다.

전체 보고서를 새로 AI 생성할 필요 없이 HWPX 생성 재요청으로 적용된다.
