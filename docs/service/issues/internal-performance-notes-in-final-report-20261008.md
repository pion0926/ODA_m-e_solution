# 성과표 내부 분석 메모를 최종 보고서에서 제외

성과지표 생성기는 측정값 선택·검토 이력과 다른 범위의 목표값을 시스템 비고로 저장한다. 기존 내보내기는 이를 성과표 비고와 해설 본문에 그대로 출력했고, 긴 셀은 내용 보존을 위해 `성과지표 상세 S1/S2`로 분리했다. 상세 번호는 새 지표나 추가 평가가 아니라 조판용 연결표시였다.

최종 보고서에서는 이 내부 메모를 생략하도록 출력 전용 필드 투영을 추가했다. 표준 생성 레코드의 필수 필드가 모두 있고, 비고가 정확히 `저장된 성과지표 분석 결과를 반영함`으로 시작하며 종료되거나 세미콜론으로 이어지는 경우에만 적용한다. 비고 열은 남기고 셀을 비우며, 같은 메모의 해설 문단과 내용 없는 해설 제목도 출력하지 않는다. 목표·실적·달성도·검증수단 및 다른 표 값은 바꾸지 않는다.

원문 파서·평가 결과·저장 본문·프롬프트·준비된 섹션 문자열은 변경하지 않는다. 따라서 분석 현재성이나 변화이론 입력 지문을 변경하지 않는다. 사용자·외부 문서의 일반 비고, 인용된 접두어, 유사 표현, 레거시 별칭 입력은 유지한다. 긴 수동 비고는 기존의 내용 보존형 분리·이어쓰기를 계속 사용한다.

표 쓰기, 섹션 미리보기 조판, 본문 해설, 최종 의미 검증이 같은 출력 투영을 사용한다. 시스템 비고는 단순히 검증을 건너뛰는 대신 실제 셀이 비어 있는지 확인한다. 목표·실적이 잘못 바뀌면 기존 검증이 계속 실패한다.

합성 회귀는 내부 메모만 제외, 수동·인용·유사 표현 보존, 실제 템플릿의 비고 빈칸, 긴 수동 비고의 무손실 이어쓰기, 혼합 레코드의 해설, 빈 제목 제거, 미리보기와 변화이론 지문 불변, 잘못된 실적과 재유입된 내부 메모의 검증 실패를 포함한다. 실제 사업 원문과 산출물 증거는 비공개 로컬 QA에 보관한다.
