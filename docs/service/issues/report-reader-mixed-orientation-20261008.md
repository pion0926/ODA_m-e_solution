# 가로·세로가 혼합된 보고서의 미리보기 크기

읽기 전용 뷰어가 첫 페이지 크기를 모든 페이지에 적용하여 가로 페이지도 세로 종이 틀 안에서 축소 표시했다. HWPX의 실제 조판과 무관한 브라우저 표시 결함이었다.

각 페이지 SVG의 크기를 보존하고 쪽 맞춤·폭 맞춤은 페이지별 종횡비로 계산한다. 수동 확대는 비율을 유지하며 현재 페이지 배율을 표시한다. 페이지 이동은 대상 페이지를 먼저 읽은 후 해당 위치로 이동하고, 이전 비동기 요청이 다시 시작한 뷰어를 덮어쓰지 않도록 세대를 확인한다. 지연 렌더링과 텍스트 선택은 유지한다.

혼합 방향의 합성 SVG에서 실제 종횡비·양방향 쪽 이동·확대·맞춤·가로 넘침을 검증하고, 기존 HWPX에서 문자 드래그 및 읽기 오류 복구를 함께 검사한다.
