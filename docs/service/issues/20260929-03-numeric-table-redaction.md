# ISSUE 20260929-03: 성과표 숫자 셀을 식별번호로 오인

## 증거와 원인

운영 knut의 `성과지표_성과지표 2차 수정` 등록 결과에서 연도와 목표값이 식별번호로 가려졌다고 표시됐다. `ai_gateway.py`의 일반 식별번호 정규식은 `20 40 60`, `2026 2027 2028` 등 공백으로 구분된 표의 숫자까지 마스킹했다. 원본 저장은 정상이나 외부 AI에 제공되는 목표·실적·기간 정보가 손실됐다.

## 수정과 완료 기준

- 공백으로 구분된 숫자열은 인접한 계좌·식별번호 등의 명시적인 라벨이 있을 때 일반 식별번호로 처리한다.
- 이메일·휴대전화·주민번호 전용 패턴과 하이픈 식별번호 보호는 유지한다. 유효한 날짜를 보존한다.
- 실제 표 배열 회귀 사례와 개인정보 보호 사례를 함께 검사한다.
- 신규 분석에는 수정된 원문을 제공한다. 이미 저장된 AI의 이전 해석은 자동으로 맞는 결과가 되지 않으므로 후속 성과 분석에서 원문과 대조한다.

운영 V2.4.2 API 배포 완료. 숫자/개인정보 37개 대상 검사와 백엔드 전체 654개·하위 사례 166개 통과. 운영 성과지표 2차 수정 PDF를 사용자 화면으로 재분석 요청하여 과거 마스킹 해석을 갱신했다.
