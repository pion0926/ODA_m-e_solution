# ISSUE 20260929-09: 계획표 수치를 보고 실적으로 오인

운영 최초 분석에서 원안 사업계획서 HWP의 연도별 목표표에 있는 합격률 90%, 취업률 75%를 actual로 추출했다. 목표/누적실적/연도별 목표가 혼합된 표에서 빈 셀이 평문 추출 시 사라졌고, 원문에 숫자가 존재한다는 검증만으로 열 의미를 보장할 수 없었다. 2027 시행계획의 설명회 2회도 목표표 인용이므로 재검토한다.

계획서 또는 산출식 표의 양성 측정값만 별도 역할 검토한다. 동일 원문 조각과 이웃 조각·표 머리글을 재사용하고 대상·단위·actual/target이 불명확한 제안은 이유와 함께 미반영한다. 일반 실적 문서의 정상 값은 추가 호출하지 않는다. 기존 계획서 양성 조합만 재검사 대상으로 되돌리고, 재검토에서 철회된 값이 화면에 남지 않도록 조정한다. 확인된 사업 실적은 계획서라는 이유로 배제하지 않는다.

별도 실적표 연결이 없는 경우에도 연결 증빙에서 측정값을 분석한 화면에 '실적 현황 원본을 찾지 못함'이라고 쓰던 안내도 실제 분석 상태에 맞췄다.

상태: V2.4.4 운영 재분석에서 합격률 90%·취업률 75%·설명회 2회를 실제값에서 철회한 것을 확인했다. 계획서의 확인 가능한 목표는 유지하며, 직접 실제값이 없는 항목은 '-'로 남긴다.
