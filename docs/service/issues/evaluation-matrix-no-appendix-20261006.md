# 평가매트릭스 상세 본문 제거

사용자 요청: 표 아래의 `평가매트릭스 상세 M1` 같은 별도 본문 제거.

기존에는 고정된 두 쪽에 표를 맞추기 위해 큰 셀을 상세 부록으로 옮겼다. 이제 별도 상세 본문과 `[M… 상세]` 참조를 생성하지 않는다. 행 높이를 계산하여 표의 다음 쪽으로 넘기며 열 제목을 반복한다. 한 행 자체가 한 쪽보다 길면 각 셀을 손실 없이 나누고 평가기준에 `(계속)`을 표시한다.

검증도 고정 페이지 수 대신 실제 행 높이·인쇄 영역·논리적 8개 평가기준의 32개 데이터 셀 연결을 확인한다. 평가 내용은 삭제하지 않는다.

- 관련 백엔드 116개 및 하위 검사 3개 통과.
- 매우 긴 셀의 연속 표 분할 및 원문 재결합 동일성 확인.
- knut 문맥 사본: 평가매트릭스 표 3쪽, 별도 M 상세 없음. 첫 쪽과 마지막 쪽 렌더 확인.
- 전체 보고서 개발 검증: 60쪽, 목차 26항목, 레이아웃 계약 및 내용 연결 통과, rHWP와 kordoc 분석 완료.
- 한컴 데스크톱 검증은 수행하지 않음.

운영 반영: V2.4.20. 배포 전 백업 production-20261006-021144 완료, 서비스 상태 정상.
운영에서 knut 보고서를 다시 생성했으며 export ID는 20a71269-2eb4-4fc0-b786-d46f6e11d9c6이다. 총 60쪽, 레이아웃 및 내용 검증 통과. 평가매트릭스는 물리 21쪽부터 시작하며 별도 상세 M 본문이 없다. 실제 미리보기에서 마지막 평가매트릭스 표 다음에 바로 평가방법이 이어지는 것을 확인했다.
