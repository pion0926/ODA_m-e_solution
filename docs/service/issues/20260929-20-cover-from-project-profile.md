# 20. 첫 페이지를 사업 기본정보만으로 작성

## 요청과 원인

사용자는 표지의 책임자·기관을 사업 기본정보에서 채우고 연결 문서와 프롬프트를 함께 개선하도록 요청했다. 기존 표지 프롬프트는 과거 자체평가서를 참고하도록 했지만 실제 운영 표지 생성은 프롬프트를 사용하지 않는 고정 형식 분기였다. 그 분기가 평가자 지정 문서를 조회하면서 미확인 값을 반환했다.

## 구현

- 현재 활성·분석 완료 사업계획서의 앞부분에서 정식 사업명과 사업책임자·국내 주관 수행기관을 분리하여 읽는다. 역할의 원문과 위치를 보존하고 값이 충돌하면 확인 필요로 남긴다. 연락처·개인식별번호는 표지에 넣지 않는다.
- 사업 기본정보에 project_manager, lead_implementer를 노출한다. 표지의 생성·조회·미리보기·HWPX 모두 이 동일 정보로 채운다.
- 표지 표기는 사업책임자/사업 수행기관이다. 템플릿의 evaluation_manager/evaluation_institution 슬롯 ID는 호환성 때문에 유지하지만 사업 담당자를 평가자로 바꾸어 부르지 않는다.
- 표지의 연동 문서는 해당 사업 기본정보의 근거 사업계획서 한 건뿐이다. 일반 자료·PDM·과거 자체평가서·평가 위촉 문서 조회 경로를 사용하지 않는다.
- Section1 표지 프롬프트와 보고서 섹션 작성 기준·연결 계약을 갱신한다. 현재 운영 표지는 외부 AI 호출 없이 기본정보를 고정 형식으로 저장한다.
- 기존 표지도 읽기 및 출력 시 최신 기본정보로 표시한다. 표지 외 생성 알고리즘과 저장 본문은 변경하지 않았다. 정확한 표지 전용 변경 해시에 한해 기존 DAC/본문 입력 호환성을 유지한다.
