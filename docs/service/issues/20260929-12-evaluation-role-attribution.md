# ISSUE 20260929-12: 과거 사업책임자를 현재 평가책임자로 표시

운영 실제 보고서 첫 표지에 과거 자체평가서 확인란의 사업책임자·제출기관이 현재 종료평가 책임자·수행기관으로 표시됐다. `_verified_execution_scope`의 정규식이 서로 다른 역할을 동일시했다. AI 오판이 아니라 서버의 잘못된 역할 연결이다.

기존 보고서/자체평가서는 현재 평가자 지정 근거로 사용하지 않는다. 명시적인 종료·외부·최종평가 수행계획/팀/위촉/계약 문서에서 정확한 평가책임자·평가수행기관 라벨을 확인할 때만 채운다. 근거가 없으면 확인 필요로 둔다. 담당자 정보 때문에 본문 생성을 막지 않는다.

보고서 생성을 UI에서 중단하고 수정 후 재개한다. 이미 저장된 자료·DAC 결과는 보존한다. 전체 재작성 확인도 기존 문서 작업과 같은 화면 내 dialog를 사용하여 내장 브라우저의 native confirm 누락을 방지한다.

검증: 과거 사업책임자·과거 평가보고서 배제, 명시적 평가계획 역할 유지, 미정·잘못된 역할 제외, 파일 누락 시 생성 지속 회귀 검사.

백엔드 전체 680개·하위 166개, 프런트 17개 및 JS 구문 검사 통과. V2.4.7 운영 배포, 백업 `.runtime/backups/production-20260929-035152`, 릴리스 `.runtime/releases/V2.4.7-validated-20260929-035215`. 기존 생성 실행 `1f0b75e0-2c7e-4581-98ba-f31aa4ff0ce6`은 UI 중단 요청 후 5개 본문을 보존하고 cancelled로 정상 종료했다.
