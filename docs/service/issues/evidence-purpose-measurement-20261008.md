# 지표 증빙 매핑에서 측정 관련성과 검증 신뢰도의 혼동

## 문제와 원인

운영 문서 재검토에서, 동일 지표의 실적표가 수치를 직접 보고해도 PDM에 적힌 검증수단 원본이 없다는 이유로 지표 연결에서 제외되는 사례를 확인했다. 반대로 교원 연수·강의계획서 등 준비 활동이 다른 측정 개념의 실적 증빙으로 연결되기도 했다. 기존 프롬프트가 측정 범위와 검증 신뢰도를 충분히 분리하지 않았다.

## 수정

- 매핑 v4에 측정 관계를 저장한다. 보고된 실적, 관찰된 이행, 실제 계산 요소, 측정된 변화만 자동 실적 연결을 허용한다.
- 자체 실적 보고의 원 대장 미첨부는 한계로 기록한다. 측정 대상·활동·범위가 일치하면 분석 대상으로 연결하며, 이 단계에서 실적을 확정하지 않는다.
- 준비 활동·계획·배경만 있는 자료는 참고로 남긴다. 교육 참석을 자격 취득으로, 장비 구입을 가동률로 바꾸지 않는다.
- v3부터 저장한 명시적 수동 연결·제외는 버전 변경 후에도 보존한다.
- 일괄 재검토 후보는 정책 버전까지 검사하여 오래된 후보를 재사용하거나 적용하지 않는다.

## 검증

자체 보고 허용·준비 활동 제외·원문 불일치 제외·구버전 자동 매핑 무효화·수동 연결 보존 회귀를 추가했다. 운영 후보를 먼저 생성하고 검토한 뒤 적용하며, 기존 성과/DAC 결과는 직접 수정하지 않고 정식 분석 작업으로 갱신한다.

의미 판단은 여전히 모델에 의존한다. 매핑 한계와 원문 출처를 사용자에게 제시하고 수동 조정이 가능하도록 유지한다.
