# 보고서 출력 공지 중복과 정량 비교 한계 표현

## 원인

출력 시 사업의 지원기관에 맞추는 기관명 투영이 서버의 고정 평가 공지까지 변경했다. 이후 공지 보완 단계가 원래 문장을 찾지 못하여 공지를 다시 붙일 수 있었다. 저장된 본문에는 공지가 한 번 있어도 출력물에는 유사 공지가 반복되었다. 같은 기관명 투영의 임시 보호 토큰 자체에 치환 대상 기관명이 포함되어 등급 명칭 보호도 불안정했다.

또한 검증하지 못한 일부 정량 비교에 대한 진단을 등급표 이유에 투영할 때, `항목의 판정을 보류함`이라는 표현이 확인된 성과의 숫자 점수까지 보류한 것으로 읽힐 수 있었다.

## 수정 범위

- 출력 투영에서 서버의 정확한 고정 공지와 평가등급 명칭을 보호한다. 일반적인 사업 지원기관 표현은 기존 투영을 유지하며, 비슷하지만 다른 문장을 고정 공지로 인정하지 않는다.
- 보호 문자열과 나머지 텍스트를 분리해 처리하므로 임시 토큰 충돌 없이 반복 출력에서도 공지가 한 번만 유지된다.
- 알려진 정량 검증 진단만 `일부 정량 비교는 원문 근거가 충분히 확인되지 않아 계산에서 제외함.`으로 표현한다. 실제 점수, 확인된 수치·기간·판단, 알 수 없는 진단과 정당한 개별 보류는 보존한다.
- 이전 버전이 이미 저장한 정확한 등급 이유 접두어도 출력 시에만 새 표현으로 바꾼다. 본문 중간의 일반 문장이나 인용문은 이 호환 변환 대상이 아니다.
- 성과 달성도에 남은 정확한 내부 실적 선택 진단은 한국어 라벨로 투영한다. 공백 변형과 다음 목표 필드 경계를 처리하며 수치, 일반 `actual` 문장과 인용은 보존한다.
- 저장된 평가와 보고서 원문, 생성 프롬프트, 분석 입력 최신성 기준은 변경하지 않는다.

## 회귀 검증

합성 본문으로 지원기관별 고정 공지 보존, 중복 방지, 반복 출력 안정성, 공지 미포함 시 한 번만 추가, 등급 명칭 보호, 변형된 기관 주장과 일반 문장 처리, 원본 불변을 확인한다. 정량 진단 검사는 확인된 금액·횟수·기간 보존 및 정당한 보류 문장의 불변을 함께 검사한다. 실제 파일 재출력과 목차·페이지 검증 결과는 개인정보가 없는 로컬 QA 기록에 보존한다.
