# ISSUE 20260929-01: 업로드 자료의 평가 포함 범위 분리

## 문제

명시적으로 승인한 PDM 이외의 PDM 버전과 중복 문서도 일반 자료로 분석·매칭되어 성과·DAC·보고서에 혼입될 수 있다. 업로드 보관과 평가 활용 여부가 구분되지 않는다.

## 완료 기준

- 원본은 보관하며 중복/구버전 PDM 등 제외 자료는 별도 필터에 사유·대조 문서와 함께 표시한다.
- 파일/정규화 본문 동일성은 AI 없이 검사하고, 문서 성격 판단은 기존 사전 판단 요청에 합친다.
- 기준 PDM과 다른 독립 설계본은 제외할 수 있으나 실적표·변경 이력·과거 연차 실적·부정적 근거를 단순히 오래됐다는 이유로 제외하지 않는다.
- 제외가 확인되면 상세 사실 추출·매칭을 건너뛰고 등록 완료 처리한다.
- 사용자가 사유를 기록하여 제외/복원할 수 있고, 기준 문서 제외·다른 계정 접근·진행 중 평가와의 충돌을 막는다.
- 성과·DAC·보고서 및 수동 매핑 후보에 제외 자료가 유입되지 않는다. 이전 성과의 제외 문서 수치도 후속 입력에서 제거한다.
- 운영 배포 후 knut 실제 문서로 확인한다.
