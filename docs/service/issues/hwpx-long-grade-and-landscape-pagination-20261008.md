# 실제 렌더에서 발견한 긴 등급표 잘림과 환류과제 제목 분리

## 실제 재현

정상 보고서 API로 27개 섹션을 완료하고 내보낸 60쪽 HWPX를 rHWP로 전부 렌더한 결과, 기존 구조·텍스트 검증만으로 놓친 세 문제가 있었다.

1. 5쪽 등급표의 긴 효율성 산정 이유와 표 테두리가 용지 하단·쪽 번호를 침범했다. 행 높이 계산이 내용을 최대 9줄로 제한하여 실제 필요한 높이를 감췄고, 페이지 분할과 검증이 모두 이 낮은 수치를 사용했다.
2. 56쪽에는 환류과제 제목만 있고 첫 표가 57쪽으로 밀렸다. 가로 용지의 본문 높이는 48,190 HWP 단위인데 첫 표 46,739에 제목 영역까지 더해졌다. 환류 표의 60,000 높이 예산이 용지 방향과 제목 공간을 반영하지 않았다.
3. 사업개요 PCP 셀의 사설 유니코드 U+F006F 세 개가 빈 글리프로 보였다. 기존 프롬프트가 사용하는 템플릿 글머리표로, 일반 렌더러에서 재현 가능한 기호가 아니었다.
4. 등급표의 질문별 이유에 서버의 수치 검증 진단이 반복 노출됐다. 확인하지 못한 제안값 목록은 실제 사업 실적이 아니며, 긴 내부 오류 문구가 사용자용 판단 설명을 가렸다.

기존 내보내기와 원본 보고서 본문은 보존한다. 공개 이슈에는 실제 사업 원문·보고서·인적사항을 포함하지 않는다.

## 수정

- 등급 이유는 상한 없이 전체 줄 수를 측정하고 첫 쪽 58,000·후속 쪽 65,000 예산에 맞추어 기준 단위로 배치한다. 한 기준 자체가 그 예산을 넘을 때만 기존 손실 없는 상세 본문 처리로 전체 텍스트를 보존한다. 단순 축약·내용 삭제·글꼴 축소는 하지 않는다.
- 이번 실제 효율성 기준의 최초 필요 높이는 63,070으로 후속 쪽 안에 들어간다. 따라서 전체 산정 이유를 등급표 한 쪽에 유지하고 별도 `평가등급 상세 G…`를 만들지 않는다. 등급표는 3쪽에서 4쪽이 된다.
- 환류·교훈 표는 실제 가로/세로 용지 높이, 상하 여백, 머리말·꼬리말과 제목 공간을 포함해 예산을 계산한다. 같은 계산을 레이아웃 검증에도 적용한다. 실제 환류 제목과 첫 표가 같은 쪽에 나타나며 제목만 있는 빈 쪽이 사라진다.
- 사업개요의 해당 고정 PCP 슬롯을 내보낼 때 정확한 U+F006F만 표준 `○`로 바꾼다. 저장 본문·프롬프트·다른 문자 및 사설 문자에는 영향을 주지 않는다.
- 별도 rHWP geometry 검증은 실제 SVG의 셀·글자 경계를 검사하여 구조상 높이만 맞는 잘린 문서를 완료 처리하지 못하게 한다.
- 등급 이유 투영에서 정확한 서버 생성 보류 문장 뒤에 이어진 `측정값 {숫자}를 지정한 원문에서 확인할 수 없음` 진단 묶음만 `정량 비교 근거가 충분히 확인되지 않아 해당 항목의 판정을 보류함.`으로 바꾼다. 모든 일반 금액·성과·기간 및 후속 판단 문장은 그대로 남긴다. 알 수 없는 진단, 단독 문장, 다른 보고서 본문에는 이 치환을 적용하지 않는다. 저장 평가·보고서 본문은 변경하지 않으며, 정상 내보내기와 슬롯 의미 검증에 같은 투영을 사용한다. 새 문장 경계가 기존 두 문장 요약을 유발해 실제 사실을 잘라내지 않도록 이 경우 후속 문장 전체를 보존한다.

## 검증

- 조판·내보내기·손실 없는 overflow 회귀 **105개와 하위 검사 3개 통과**. 800자·5,000자 이유, 원문 보존, 전체 표 높이, 가로 용지 제목 여백을 포함한다.
- 기존 실제 60쪽 내보내기를 복사한 오프라인 후보에서 **11개 질문 산정 이유 전부 보존**을 확인했다. 원본 파일은 변경하지 않았다.
- 실제 후보를 다시 rHWP 렌더하여 등급표 4~7쪽의 잘림 없음, 효율성 이유 전체가 6쪽 안에 들어감, 57쪽 환류 제목과 첫 표 결합, 17쪽 표준 동그라미 글리프를 직접 확인했다.
- 후보의 변경된 쪽 번호는 운영 내보내기의 정상 목차 재계산 과정에서 확정해야 한다. 오프라인 후보는 운영 최종 내보내기나 한컴 데스크톱 검증으로 주장하지 않는다.
- 최초 조판 후보 독립 검증에서 60쪽 모두 SVG geometry 오류 0건, 원문 텍스트 조각 1,051개 전부 보존을 확인했다(알려진 글머리표 치환 제외).
- 진단 가독성 추가 후보는 11개 이유 중 1개에서만 알려진 진단 묶음을 치환했다. 나머지 사실 전체의 보존을 확인했으며, 실제 6쪽에서 기술 진단이 사라지고 정상 판단 설명과 2.5점 소계가 온전히 보인다. 해당 기준의 높이는 51,370으로 줄었다. 원본 HWPX·DB는 보존한다.
- 진단 투영·점수·기존 조판·PCP 기호를 포함한 최종 관련 회귀 **121개와 하위 검사 3개 통과**. 알려진 진단의 원문형/문체 정규화형, 반복 숫자, 정상 금액·횟수·기간, 알 수 없는 진단, 다른 슬롯, 반복 투영을 검사했다.

실제 운영 배포·최종 내보내기·독립 geometry 검증 결과는 최종 QA 기록으로 확인한다.
