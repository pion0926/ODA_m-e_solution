# ISSUE 20260929-05: 실적표의 등록 사실·매핑이 모두 누락

## 운영 증거

knut `성과지표_5차년도 지표별 실적 현황_2026-06-30_교통대.xlsx`의 등록 분석에서 제안 사실 25개가 모두 원문 검증을 통과하지 못했고 사실/매핑 0개로 저장됐다. 원본에는 CPCR 강사 목표 10명·실적 6명 등 25행이 정상 추출돼 있다. 업로드는 완료되어도 이후 지표별 검토 계획에서 누락될 수 있는 문제다.

## 수정

기존 운영 코드로 실적표 1개를 재검증한 결과 18개 사실 모두 탈락했다. AI가 `A2=`, `B2=` 등의 셀 주소를 생략한 인용문을 반환했고, 수치는 인용에 있었지만 원문 연속 일치는 전부 실패했다. 진단 응답은 `.runtime/production-userflow-20260929/registration-quote-probe.jsonl`에 보존했다. 평가·문서 결과는 변경하지 않았다.

AI가 표의 셀 주소와 구분자가 포함된 인용문을 다시 쓰도록 하지 않고, 서버가 생성한 원문 조각 ID를 선택하게 한다. 서버가 선택된 원문을 그대로 복사하고 수치·지표 ID·질문 ID·산출물 범위를 다시 검증한다. 유효하지 않은 근거나 제안 수치는 계속 거부하며, 문서 전체 처리를 실패시키지 않는다. 기존 인용 응답은 호환하되 검증을 느슨하게 하지 않는다.

## 완료 기준

표 숫자·셀 주소가 보존되고 잘못된 ID·없는 수치는 승인되지 않을 것. 배포 후 해당 자료를 사용자 재분석 흐름으로 다시 등록 분석하고, CPCR 성과 분석 후보에 포함되는지 확인할 것. 운영 사실·평가 DB에 수치를 직접 주입하지 않는다.

운영 V2.4.2 API에 반영하고 V2.4.3 화면에서 실제 재분석했다. 해당 실적표는 등록 사실 77건·PDM 매핑 5건으로 복원됐다. CPCR 지표 `outputs-3-1-1`에 원문 셀 C17=10명(목표), D17=6명(실적), 9월 완료 예정 한계가 각각 연결됨을 DB 읽기 전용 조회와 화면으로 확인했다. 전체 654개·하위 사례 166개 백엔드 검사 통과. 후속 성과 분석 검증 진행 중.
