# 성과 분석 저장으로 자기 현재성이 무효화되던 문제

성과 분석은 저장 전 프로젝트 전체 workflow 지문을 결과 안에 넣고, DAC는 저장 후 지문과 비교했다. 전체 지문에는 PDM 결과 자체도 포함되어 있어 같은 자료를 방금 분석한 결과가 오래된 것으로 표시될 수 있었다. DAC·보고서의 정책과 파생 결과도 성과 분석 입력과 섞여 있었다.

성과 전용 입력 영수증을 추가했다. 기존 문서 digest와 canonical digest를 재사용하며 프로젝트, 활성 문서와 상태·본문 해시, PDM 원본 셀, 목적·수동 매핑, PDM 관련 등록 사실, 실행 모델, 성과 추출·집계·권고 정책의 배포 소스를 구분해 기록한다. 원문 파일과 대형 분석 캐시는 현재성 조회에 다시 적재하지 않는다. 저장한 PDM 결과·DAC·보고서 출력은 이 영수증에 포함하지 않는다.

기존 영수증이 없다는 이유로 자동 최신 승격하지 않는다. 사용자가 일반 사전검토에서 현재성 재검증을 실행할 수 있고, 기존 history의 버전 호환·집계 범위·차원·문서×지표 검증과 동일 모델 조건을 통과한 측정 기록은 원문·권고 AI 재호출 없이 보존한다. 지원되는 과거 측정 버전도 해당 검증을 통과하면 재사용한다. 모델·추출 정책이 달라진 조합은 재검토하며, 추출 구현 변경 시 문서 내부의 이전 추출 캐시도 재사용하지 않는다. 부분 실패와 목적 검토 대기 상태는 최신으로 표시하지 않는다.

수동 매핑 저장 직후 접수 입력을 동결한다. 대기 중 문서·지표·매핑·정책이 달라지면 명시적 재검토를 요청한다. 모델만 변경되면 실행 시점 모델에 맞춰 사용자가 확인한 조합 안에서 재분석 대상을 다시 계산한다. 실행 중에는 이미 바인딩한 모델을 유지한다. 작업 종료 직전에도 기존 전체 snapshot과 성과 입력을 모두 확인하며, 변경되면 이전 결과를 보존하고 재실행을 안내한다.

합성 회귀는 자기 저장 이후 현재성 유지, 문서 추가·교체·평가 제외·원문 재분석·지표·수동 매핑·등록 사실·모델·정책·프로젝트 변경의 무효화, 구 영수증 재검증, 원래 측정값·출처·권고 보존과 AI 호출 0건, 대기 모델 변경의 범위 유지, 추출 캐시 비호환을 검사한다. 실제 데이터와 평가 수치는 이 문서에 포함하지 않는다.

성과 버전 추가에 따른 전체 평가·보고서의 보수적 현재성 경계는 유지한다. 이행 후에는 정상 성과 재검증, DAC, 보고서 생성 순서로 최신 결과를 확인해야 하며, 운영 결과를 수동 수정해 통과시키지 않는다.
