# ISSUE 20260929-16: 평가등급표의 판단 문장 중간 잘림

실제 운영 보고서 등급표에서 `등을 식별하고 일부; 해당 사실을 질문별 점수 산정에 반영함.`처럼 불완전한 문장이 발생했다. 저장된 DAC 판단을 연결하는 `grade_question_reason`이 90자 제한에 맞춰 단어 단위로 자른 다음 일반 종결 문구를 붙인 원인이다. AI 원문 오류가 아니다.

문자 제한을 권고값으로 바꾸고, 첫 두 문장을 온전히 보존하여 긍정 사실 뒤의 한계도 남긴다. 소수점·날짜는 문장 경계로 오인하지 않는다. 짧은 경우 세 번째 문장까지 유지하며 긴 문장은 HWPX 표의 기존 페이지 분할로 처리한다. 점수·등급은 변경하지 않는다. 운영 재생성에서 등급표 완결 문장과 실제 HWPX 넘김을 확인한다.
