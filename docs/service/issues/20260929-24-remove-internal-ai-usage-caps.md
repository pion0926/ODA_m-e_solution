# 자체 AI 사용량 한도 해제

사용자가 2026-09-29 자체 사용량 제한 해제를 명시적으로 요청했다. 임시 5천만 확대 요청을 대체하며, 테스트 후 기존 한도로 복구하지 않는다.

- 개발·운영 Compose: `AI_USAGE_LIMITS_ENABLED=false`, `AI_JOB_SECONDS=0`.
- 토큰·요청 횟수·전체 비용·계정 비용·작업 비용의 서비스 자체 상한 검사를 비활성화한다.
- 작업 전체 1시간 상한은 해제한다. 개별 네트워크 요청 타임아웃, 재시도 횟수, 사용자 취소는 유지한다.
- `AI_GLOBAL_BUDGET_ENABLED=true`는 유지한다. 해당 경로를 끄면 사용량 기록과 프로세스 간 전체 동시 요청 제어도 없어지기 때문이다.
- 사용량 예약/실제 정산 기록과 전체 동시 AI 요청 4개 제한은 계속 적용한다. 공급자 모델이나 API 키는 바꾸지 않는다.
- 회귀 테스트: 제한을 넘은 요청 허용 및 기록 유지, 4개 동시 실행 제한, 명시적 한도 재활성화, 전체 실행 시간 상한 해제, 보고서 재개 관련 10개+3 subtest 통과.

운영 반영 후 한도 때문에 중단된 신규 프로젝트 27건과 PDM 원안 재검증부터 전체 테스트를 이어간다.
