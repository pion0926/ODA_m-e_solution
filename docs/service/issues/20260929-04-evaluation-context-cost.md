# ISSUE 20260929-04: DAC 범위 확대와 보고서 입력의 반복 비용

## 근거

`docs/service/token-usage-audit-20260925.md`의 실제 개발 테스트에서 11개 질문 전부 확대됐고, DAC 누적 약 900만 토큰·보고서 20개 약 625만 토큰이 확인됐다. limitation 존재를 충돌로 간주한 전 문서·전체 본문 확대, 범위 변경 시 캐시 폐기, 상세 평가의 중복 원문 반복 전송이 원인이었다. 운영 전체 흐름을 재개하기 전에 같은 실패 경로를 수정한다.

## 완료 기준

- 긍정과 한계가 함께 존재하는 정상 평가를 근거로 전 자료를 다시 읽지 않는다.
- 직접 근거가 없는 질문만 관련 문서의 미검토 구간으로 한 차례 확대한다. 자동 확대가 전체 검토를 완료했다고 주장하지 않는다. 사용자 전체 검토 선택은 유지한다.
- 같은 원문·규칙·모델·산출물 조건의 검토 완료 구간을 범위 확대에도 재사용한다. 모델/원문/정책 변경은 캐시를 무효화한다.
- 보고서 입력에서 확정 점수·보류·모든 세부지표·수치·반대 근거·출처를 보존하면서 중복된 원문만 정리한다.
- 회귀 검사 후 개발/운영 배포, 실제 DAC 및 보고서 완료로 검증한다. API 예산 상향으로 우회하지 않는다.

운영 V2.4.2 API에 반영 완료. 범위 확대/축소 시 기존 완료 구간의 재사용·필터링, 모델·원문 변경 시 재검토, 보고서의 점수·보류·수치·반대근거 보존을 검증했다. 전체 654개·하위 사례 166개 통과. 실제 DAC/보고서 생성 확인은 이어서 진행한다.
