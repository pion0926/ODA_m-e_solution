# DAC 최초 조회 중 예시 점수 노출

## 원인

DAC 보드의 정적 HTML에 예시 점수·등급·증빙 건수·대기 건수가 남아 있었다. 로그인 확인과 대시보드 조회가 평가 결과 조회보다 먼저 완료되면, 실제 저장 결과로 교체되기 전까지 해당 값이 표시될 수 있었다. 별도 평가 상태 응답도 결과 조회 완료 여부와 구분되지 않았다.

## 수정

- 최초 화면은 점수·등급·증빙 건수를 중립적인 빈 값으로 표시하고 저장 결과 조회 중임을 안내한다.
- 평가 상태 API나 대시보드 응답만으로 평가 결과가 없는 것으로 단정하지 않는다. 실제 결과 응답 후 저장된 점수와 등급을 표시한다.
- 최초 조회 실패는 평가 전·판정보류와 구분한다. 이후 결과 갱신 실패는 마지막으로 확인한 점수와 세부 판단을 보존하고 갱신 실패를 안내한다.
- 점수 요약의 `aria-busy`와 상태 안내로 조회 진행 및 실패를 구분한다.

## 회귀 검증

실제 서비스 HTML과 스크립트를 실행하는 Playwright 검사에 합성 API 응답을 연결한다. 평가 상태 응답은 먼저 보내고 결과 응답을 지연시켜 최초 진입·새로고침 중 예시 점수가 노출되지 않는지 확인한다. 실제 응답 후 점수·등급 반영, 최초 조회 실패, 후속 갱신 실패 시 저장 점수 및 세부 판단 보존을 함께 검사한다. 외부 서비스나 유료 AI는 호출하지 않는다.
