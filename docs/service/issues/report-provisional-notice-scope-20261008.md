# 내부 잠정 진단 고정 공지가 사업기관 혼입으로 잘못 차단되는 문제

## 원인과 영향

운영의 신규 보고서 생성에서 적절성·일관성 섹션이 `현재 사업개요에 없는 KOICA·코이카 정보가 혼입됨`으로 실패했다. 서버가 자동 첨부하는 `PROVISIONAL_NOTICE`는 KOICA·국무조정실의 공식 확정평가가 아니라는 안내인데, 사업기관 혼입 검사가 이 문구의 KOICA 토큰까지 현재 사업의 소관기관 주장으로 취급했다. 제한된 AI 수정·복구 후에도 서버가 같은 고정 공지를 다시 붙이므로 모델의 수정으로 해결할 수 없는 충돌이었다.

정상 조회 API로 보존한 실제 실패 초안 두 건은 KOICA 언급이 각 한 번뿐이었고 모두 이 정확한 공지에 포함되어 있었다. 총점·기준 점수 검증은 두 건 모두 통과했다. 실제 문서 본문·진단 파일은 커밋하지 않는다.

## 수정

`report_generator._validate_reader_content`의 **사업기관 혼입 검사에 사용하는 문자열에서만** 서버의 정확한 `PROVISIONAL_NOTICE`를 제외한다. 저장 본문과 HWPX 입력에서는 공지를 유지한다. 일반 면책 문장이나 변형된 공지를 포괄적으로 허용하지 않으며, 같은 본문에 들어간 별도의 KOICA 소관·지원·정책 주장은 계속 차단한다. 인용·사실·점수 검증과 AI 재시도 한도는 유지한다.

추가 감사에서 총점 보류 검사가 `적절성 종합점수는 3점임`처럼 **저장된 개별 기준 점수**까지 5대 기준의 총점 확정으로 오인하는 별도 경계를 합성 재현했다. 명시적 기준명과 저장된 같은 점수가 있는 국소 주장에 한해서 총점 검사와 구분한다. 전체·5대 기준·20점·총점 맥락, 다른 숫자, 보류 기준 점수, 허위 KOICA 등급은 계속 차단하며 기존 과거 평가·예시 구분은 유지한다.

## 검증 및 복구

- 합성 회귀: 일곱 보고서 섹션의 정확한 고정 공지 허용·본문 보존, 공지 옆 실제 기관 주장 차단, 일반·변형 면책 문구 차단, 개별 기준 점수와 총점 범위 구분. 관련 보고서·점수·품질 검증 총 **81개와 하위 검사 2개 통과**.
- 실제 실패 초안 두 건을 네트워크가 차단된 QA 컨테이너에서 새 검증 함수로 대조하여 **본문 검증 오류 0건·점수 검증 오류 0건**을 확인했다. 원문은 외부 AI에 재전송하지 않았다.
- 운영 복구는 현재 생성 배치가 종료된 뒤 검증된 이미지 배포와 정상 보고서 재개 API로 수행한다. 성공 섹션을 보존하며 실패 섹션만 다시 처리한다. 운영 반영·재개 완료 여부는 별도 검증 결과로 기록한다.
