# 성과지표 증분 반영의 집계 범위와 목표 근거 보존

상태: 코드 및 모의 AI 회귀 검증 완료. 실제 운영 배포·사업 데이터 검증은 전체 배포 기록과 QA 결과에서 별도로 확인한다.

## 확인한 문제

1. `performance_delta.reconcile`이 단위와 기준일만 비교했다. 기존 누적 6회에 최신 개별 행사 1회가 들어오면 1회로 바뀔 수 있었다. 기관·집단 또는 월간/연간 범위도 구별하지 않았다.
2. 원문이 한 행사의 실제 개최를 입증하더라도 문자 그대로 `1회`가 없으면 수치 검증에서 버렸다. 반대로 개별 행사 식별 계약이 없어 안전하게 누적할 수도 없었다.
3. 변경된 실제 증빙 매핑에서 계획 자료가 빠지면 그 문서에서 확인했던 목표치도 함께 사라졌다. 실제 수행 증빙과 목표 정의의 역할이 분리되지 않았다.
4. 신규 문서×지표 조합이 없어도 매핑 해제에 따른 기존 결과 재정리가 필요하지만, 실행 조건과 changed 집합이 신규 조합에만 의존했다.
5. 문서별 마지막 한 개 측정 캐시만 저장하고 이전 평가의 모든 근거·위험 문단을 새 요청에 넣어, 실패 후 재개·새 매핑에서 불필요한 재요청과 컨텍스트가 생길 수 있었다.

## 변경

- 측정 계약 `pdm-evidence-v8-scope`: 누적, 기간 합계, 개별 행사, 미확인 범위 및 기간 단위를 저장한다. 대상·범위가 다르거나 누적/개별 실적이 섞이면 합산·덮어쓰기를 보류한다.
- 혼합 자료에서도 원문으로 검증된 누적 실적은 최신 기준일·동일일 높은 수치 규칙으로 표시한다. 추가 행사가 이미 포함됐는지는 별도 확인 필요로 남기고 달성률은 확정하지 않는다. 근거 없는 이전 0이나 빈 값이 검증된 누적값을 가리지 않으며, 누적 10회와 새 행사 1회를 자동으로 11회라고 만들지 않는다.
- 개별 행사 1회는 실제 완료, 행사명, 장소, 시작일·종료일의 원문 근거와 별도 역할 검증이 모두 필요하다. 팀·참가자·세션·문서 수를 행사 횟수로 환산하지 않는다.
- 날짜 구간이 겹치는 행사 보고는 보수적으로 한 건만 반영하고 근거 문서 전체와 중복·모호성 안내를 보존한다. 서로 겹치지 않는 검증된 행사 구간은 합산한다. 월별/연간 지표는 해당 최신 집계 기간만 비교한다.
- 활성 자료의 기존 목표 인용과 현재 PDM에 연결된 등록 target 사실을 실적 매핑과 독립적으로 보존한다. 원문을 다시 대조하고 지표 단위를 검증한다. 일반 참고자료 목표에는 공식 PDM 목표 확인 필요를 표시하며, 명시된 PDM 목표가 항상 우선한다. 평가 제외·삭제 자료와 이전 PDM의 등록 사실은 재사용하지 않는다.
- 매핑 또는 목표 근거만 바뀌어도 명시적 분석 실행으로 재정리한다. 신규 원문 조합이 없다면 측정 AI를 다시 호출하지 않는다.
- 내용·모델·지표·선별된 이전 판단을 포함한 digest별 최근 4개 캐시를 유지한다. 비교 맥락에서는 반복된 전체 근거·위험 문단을 제거한다.
- 기존 쌍은 횟수·명수·건수 등 수량 지표에 한해 새 범위 규칙으로 한 번 재검토한다. 이전에 검증된 비율/승인 지표는 재사용한다. 모델 변경만으로 완료된 모든 쌍을 재분석하지 않는다.

## 검증

격리 QA 컨테이너, 운영 접근 및 유료 AI 호출 없이 수행:

- 관련 백엔드 88 tests와 20 subtests 통과.
- 프런트 계약 18 tests 통과.
- 동일 행사 여러 문서, 서로 다른 날짜 행사, 여러 날 행사와 마지막 날 보고 중복, 같은 날 다른 명칭, 월별 범위, 누적 6회/개별 1회 혼동, 연간/월간 혼동, 미검증 행사, 대상 집단 차이 회귀 포함.
- 매핑 제거만으로 실적 회수 및 목표 유지, 제외 자료 목표 제거, 등록 목표 원문 불일치, 신규 조합 캐시 재사용, 선택적 이전 쌍 무효화 회귀 포함.

## 명시적 한계

같은 날짜에 실제로 서로 다른 행사가 있어도 원문만으로 독립성을 확정할 수 없으면 한 건의 하한값만 반영하고 안내한다. 누적 통계와 개별 행사 간 포함 관계, 부분 집단 간 중복 인원은 추정하지 않는다. 원문에 없는 목표·실적·자격을 자동 보완하지 않는다. 이러한 경우는 시스템 실패 대신 비교 보류/근거 확인 필요로 남긴다.

## 목적 매핑 v3 → v4 전환 보호

- 재검토 건수는 현재 선택된 조합 중 이전 기록은 있지만 재사용할 수 없는 조합만 집계한다. 이미 연결에서 빠진 과거 기록을 전체 건수에 넣지 않는다.
- 아직 v4 목적 검토를 받지 않은 v3 자료는, 같은 PDM·지표에서 이전 실행의 검토 기록 또는 관측 출처가 있는 조합에 한해 `deferred_mappings`로 별도 보존한다. 검토한 적 없는 주제 매핑은 자동으로 복구하지 않는다.
- 전환 보존 자료는 신규 자동 연결이나 수동 연결로 승격하지 않는다. 이전 확인값을 참고 결과로 보존한다는 안내와 `mapping_review_required`를 남긴다.
- 신규 문서는 정상 분석하며 같은 지표의 기존 검증값과 일반 범위 비교 규칙으로 조정한다. v4 재매핑이 끝나 제거된 연결이나 사용자의 명시적 제외는 전환 보호로 되살리지 않는다.
- 관련 백엔드 102 tests·20 subtests 통과. 운영의 다른 프로젝트는 수정하지 않았다.
