# 문서 목적 기반 성과지표 증빙 매핑

## 원인

등록 사실의 주제 연결과 실적 증빙 연결이 같은 목록에 합쳐졌다. AI 매핑은 원문 존재와 신뢰도 0.45만 확인했고, 사실의 지표 ID를 신뢰도 0.7로 자동 승격했다. 오래된 자료에는 파일명 단어 매칭도 적용됐다. 분석 준비 화면에서 추천을 그대로 실행한 경우에도 전체 선택이 사용자 지정으로 저장돼 다음 분석에 고착됐다.

## 변경

- `document_evidence_purpose.md`: 문서의 주된 유형, 작성 목적, 사업 내 역할과 인터뷰 목적·응답 대상 분석을 추가한다.
- `pdm_mapping_policy.py`: 직접 이행 기록·계산 원자료·지표에 부합하는 정성 증빙을 구분한다. 대상·활동·범위 일치, 입증 사실·원문, 신뢰도 0.75 이상을 자동 연결의 필수 조건으로 삼는다.
- 목표/계획/배경/미확인은 참고 분류로 보존한다. 등록 사실에서의 무조건 승격 및 자동 분석 대상의 파일명 대체 매칭을 제거한다.
- 최종 합계가 명시되지 않은 개별 행사 결과·명부도 증빙이 될 수 있다. 등록 단계에서 행사 횟수나 달성도를 자동 산정하지는 않는다.
- 준비 화면에 입증 사실·한계를 표시한다. 추천 수락과 직접 추가/제외를 구분해 저장한다.
- 기존 일괄 확인 데이터에서는 원래 자동 추천에 없던 추가만 수동 추가로 식별한다. 자동 추천과 일치했던 명시적 사용자 선택은 기존 데이터만으로 구분할 수 없으므로 과거 연결을 이력에 보존한다.
- 업로드 목록에서 문서 목적·사업 역할·인터뷰 목적을 확인할 수 있다.

## 기존 자료 전환

`python -m kodame_intake.remap_evidence_purpose prepare --root <비공개 후보 디렉터리>`로 현재 프로젝트 모델을 사용해 후보를 생성한다. 외부 원문 전송 승인 범위 내에서만 실행한다. 문서별 후보를 재사용하며 실패 항목만 재시도할 수 있다.

`apply`는 프로젝트별 작업 잠금·활성 작업 확인·본문/분석/기준 문서 변경 검사를 수행한다. 모든 후보가 현재 입력과 일치해야 트랜잭션으로 교체한다. 기존 매핑은 문서 분석의 `mapping_history`에 보관하고 평가·보고서 본문·측정 이력·계정·세션은 수정하지 않는다. 입력 변경 시 기존 보고서의 최신성 확인은 다시 필요하다.

재검토 전 구버전의 자동 연결은 신규 분석에 자동 선택하지 않으며 준비 화면에 대기 건수를 알린다. 기존 평가의 연결 목록이 바뀌면 이전 평가 값이라는 안내를 표시한다. 과거 수치의 삭제나 재산정은 수행하지 않는다.

## 검증과 배포

- 백엔드 752개 및 하위 검사 166개, 프런트엔드 18개 통과.
- Playwright 22개 통과: 입증 목적·한계 표시, HTML 이스케이프, 사용자 추가 유지, 로그인 복구와 보고서 미리보기 회귀 포함.
- 운영 적용 전 immutable API·웹 이미지 검증과 백업, 진행 작업 점검, 활성 세션 지문 비교를 수행한다. 쿠키명·세션 저장소·인증 설정은 변경하지 않는다.
- 기존 자료 재분석과 운영 반영의 실제 결과는 완료 시 이 문서에 추가한다.
