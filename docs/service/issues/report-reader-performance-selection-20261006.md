# 전체 보고서 미리보기: 초기 배율·드래그·로딩

## 원인과 수정

기존 전체 미리보기는 Studio 편집기를 초기화하면서 사용자 저장 배율을 적용했다. 서비스 읽기 전용 가드가 pointerdown/mousedown과 복사 키까지 막아 글자 선택이 불가능했다.

완료된 `/api/v2/report/exports/{id}/download` 미리보기만 전용 읽기 화면으로 분리했다. 동일 버전 @rhwp/core 0.8.6에서 Web Worker로 원본 HWPX를 해석하고 첫 쪽과 스크롤 인근 쪽만 SVG로 렌더링한다. 편집기·CanvasKit 초기화가 필요 없다. SVG 텍스트는 브라우저 기본 드래그/복사를 지원하며 편집 엔진을 로드하지 않는다. 초기에는 뷰포트 높이·너비에 맞추되 100%를 넘지 않는다. 사용자가 쪽 맞춤·폭 맞춤·확대·축소·쪽 이동을 선택할 수 있다.

SVG 내 클리핑 ID가 페이지마다 같아 여러 페이지를 inline 표시하면 뒷쪽 글자가 앞쪽 클립에 잘릴 수 있다. 페이지별로 모든 ID와 참조를 분리했다. 스크립트/이벤트/외부 리소스를 제거하고 링크는 텍스트를 보존하여 비활성화한다. 실패 시 오류와 다시 시도 버튼을 표시한다.

부분 미리보기와 서버 조판은 기존 Studio 경로를 유지한다. 빌드 스크립트가 로더와 버전 고정 코어를 재현하며 자산 해시를 기록한다. 공개된 vendor 코어만 장기 캐시하며 보고서/API에는 이 캐시 정책을 적용하지 않는다. 텍스트·WASM 압축을 사용한다.

## 확인

- Playwright 전체 20건 통과. 최종 경로/클립 변경 후 해당 6건 재통과.
- 실제 마우스로 SVG 글자를 드래그하고 선택 문자열 발생 확인. Backspace로 원문이 변하지 않음.
- 초기 배율 100% 이하, 첫 렌더가 전체 페이지보다 적음, 쪽 이동, 다운로드 오류 후 재시도, 페이지간 ID 유일성 검증.
- 프런트 상태/계약 18건 통과.
- 운영 60쪽 보고서 사본 로컬 검증: 첫 SVG 표시 약 0.34초, 초기 69%, 최초 1쪽 렌더. 21·23·60쪽 표시와 콘솔 오류 없음 확인. 네트워크를 모의 제공한 로컬 측정이며 운영 인터넷 다운로드 시간을 포함하지 않는다.
- 원본 HWPX·저장된 분석·보고서 DB를 변경하지 않았다. 한컴 데스크톱 검증은 수행하지 않았다.
