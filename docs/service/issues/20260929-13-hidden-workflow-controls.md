# ISSUE 20260929-13: 실행 중 작업에 이어쓰기 버튼 노출

실제 운영 보고서가 실행 중인데 '남은 섹션 이어서 생성' 버튼이 함께 보였다. DOM의 `hidden=true`는 정상이나 공통 `.btn { display:inline-flex }`가 브라우저의 기본 hidden 표시 규칙을 덮었다. 서버의 중복 실행 방지는 동작하지만 화면이 혼동을 준다.

공통 `[hidden] { display:none!important }` 규칙을 추가하여 워크플로가 숨긴 요소가 구성요소 display 규칙으로 다시 나타나지 않도록 한다. 분석 로직·저장 데이터는 변경하지 않는다. 실제 보고서 종료 후 웹만 배포하고 실행/완료 상태를 확인한다.

완료: 이슈 14 수정으로 보고서를 정상 중단한 시점에 V2.4.8과 함께 운영 반영했다. 운영 DOM에서 hidden 요소 30개 중 잘못 표시된 요소 0, 실제 생성 중 `reportResume.hidden=true`, 계산된 display=none을 확인했다.
