# ISSUE 20260929-17: 표 상세 설명의 과도한 새 페이지와 빈 페이지

실제 HWPX 생성·검증은 성공했지만 75쪽 전체 이미지 점검에서 평가매트릭스의 짧은 상세 12건을 각각 새 페이지로 만들고 PDM 뒤에 빈 페이지가 생긴 것을 확인했다. `append_table_details`가 셀마다 pageBreak를 넣고 종료 후 빈 운반 문단에도 강제 pageBreak를 둔 원인이다.

상세 설명 전체에 공통 페이지 예산을 적용해 짧은 여러 항목을 같은 페이지에 배치한다. 긴 원문은 기존처럼 안전한 줄 길이와 페이지 예산으로 나누고 원문 문자·공백·유니코드·참조 ID를 보존한다. 마지막 운반 문단의 강제 쪽 나누기는 제거한다. 보고서 본문과 AI 결과는 변경하지 않으며 HWPX만 다시 출력한다.

회귀 99개·하위3개 통과. 개발서버에서 실제 운영 HWPX 사본의 14개 상세 블록만 새 함수로 재배치한 검증본은 75쪽에서 61쪽으로 감소했다. Kordoc 겹침 위험 0, PDM 뒤 빈 페이지 제거와 평가매트릭스 상세 12건의 2쪽 통합을 이미지로 확인했다. 이 검증본은 출력 함수만 시험한 사본이며, 최종 제공 파일은 배포 후 실제 서비스 UI에서 다시 생성한다.
