# ISSUE 20260929-14: 저장된 성과지표 결과가 보고서에 전달되지 않음

실제 성과지표 화면은 승인 목표/실적 유/유, CPCR 목표20명/실적6명인데 보고서 성과달성도는 '최신 PDM 목표 미기재'와 '승인 공문 대조 미확인'으로 되돌아갔다. 보고서 컨텍스트에 PDM 설계 계층만 있고 별도 성과 분석의 검증·선택값이 빠져 있었다.

평가 대상 문서로 필터한 현재 성과 분석 결과와 선택 근거를 보고서 작성/검토/복구 컨텍스트에 전달한다. PDM은 지표 설계의 기준이고 목표·실적은 연결 문서에서 보완된다는 규칙을 명시한다. HWPX용 성과지표 행은 지표 ID에 따라 저장된 목표·실적·달성률·정성 충족 상태를 서버가 연결한다. 수치·유/무를 AI가 다시 추측하거나 지우지 않는다. 해석 서술은 AI가 맡되 충돌·미완료·다른 기간 목표의 한계를 함께 전달한다.

운영 보고서는 UI 중단 후 수정·배포하여 재검증한다. 새 수치를 DB에 주입하지 않으며 기존 성과 분석 결과를 재사용한다. 선택 근거 문서 ID도 보고서 출처에 기록한다.

검증: 백엔드 전체 685개·하위 166개 통과 후 숫자 0 보존 추가 보완은 집중 6개 재검증 통과. 실제 운영 자료의 읽기 전용 사본으로 성과·산출물 12행을 기존 HWPX 파서로 처리했고 승인 유/유, CPCR20명/6명 값과 3,823자 본문을 확인했다. 원본 성과 모델은 변경하지 않았다. V2.4.8 배포, 백업 `.runtime/backups/production-20260929-040914`, 릴리스 `.runtime/releases/V2.4.8-validated-20260929-040940`.
