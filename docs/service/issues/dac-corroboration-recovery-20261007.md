# DAC 교차검증 출처 오류의 항목별 복구

## 원인

`relevance-q1`의 AI 출력에서 `source_families[].evidence_ids`가 같은 세부지표의 선택 증빙에 포함되지 않으면 `score_question`이 예외를 발생시켰다. 선택적인 출처 독립성 설명의 오류가 세 번의 재시도 후 질문 전체 중단으로 이어졌다.

## 처리 기준

| 케이스 | 처리 |
| --- | --- |
| 출처 그룹 없음/null | 교차검증 가점 없이 계속 |
| 출처 그룹이 배열이 아니거나 원소가 객체가 아님 | 해당 그룹 제외, 적용 규칙에 사유 기록 |
| 빈 증빙, 문자열/중첩 배열 등 ID 형식 오류 | 해당 그룹 제외 |
| 존재하지 않는 증빙, 다른 질문의 증빙, 같은 지표에서 선택하지 않은 증빙 | 그룹 전체 제외; 일부 ID만 남겨 출처 귀속을 추정하지 않음 |
| 원출처 이름 누락, 독립성 설명 불충분, 원본 식별정보 누락 | 해당 그룹 제외 |
| 유효한 독립 출처 둘 이상 | 기존 교차검증 점수 계산 유지 |
| 주 판단 증빙의 허위 ID·다른 질문 인용 | 기존 재시도 및 검증 실패 유지 |
| 정량 수치의 원문 검증 실패 | 기존 항목 미확인 처리 유지 |
| 출력 구조/필수 판단의 오류, 공급자 실패 | 기존 제한 재시도와 완료 질문 보존 유지 |

`dac_corroboration.py`에서 선택적인 출처 그룹만 검증한다. 기본 판단 근거에 ID를 자동 추가하지 않으며 원출처 정보도 생성하지 않는다. 제외 사유는 해당 체크의 `applied_rules`에 남는다. 유효한 그룹만 반환하고 원래 AI 응답을 직접 수정하지 않는다. 독립 교차검증이 성립하지 않으면 기존의 출처 4등급 제한과 증거 신뢰도 계산이 적용된다.

프롬프트에도 같은 세부지표의 선택 증빙만 사용하고 독립성을 입증할 수 없는 그룹은 빈 배열로 반환하도록 명시했다. 프롬프트 버전은 v13이다.

## 검증 및 배포 범위

- 선택하지 않은 증빙/미등록/다른 질문/잘못된 형식/빈 값/출처 설명 누락의 회귀 사례.
- 정상 교차검증 인정, 잘못된 주 판단 근거 거절, 입력 불변성, 점수 부풀림 방지 확인.
- 질문 평가 흐름에서 선택적 그룹 오류로 추가 AI 재시도 없이 다음 질문까지 진행하는 테스트.
- DAC 관련 테스트 99개 및 하위 사례 51개 통과. 유료 AI 실문서 재평가는 이번 변경 검증에 실행하지 않음.
- 개발서버(8002) 반영 완료.
- 2026-10-08 운영 V2.4.25 배포 완료(API 이미지 승격, 웹 이미지 유지). 배포 전 활성 작업 0건 및 DB·파일 암호화 백업 완료. 운영 API·작업자 건강 상태, 외부 `/healthz` 200, 프롬프트 v13과 교차검증 복구 함수 로드 확인.
- 세션 초기화나 인증 설정 변경은 하지 않았다. 전체 세션 행 수는 배포 전 5개/후 2개로 동일성 검증은 성립하지 않았다. 시작 시 만료 세션을 삭제하는 기존 로직이 있으며, 모든 기존 쿠키의 실제 재인증 검증은 수행하지 않았다.
- 중단된 평가의 실제 재실행은 이번 배포 범위에 포함하지 않음.

## 승인 후 운영 재실행

2026-10-08 사용자의 별도 승인 후 기존 계획에 선택된 57건의 증빙 구간을 대상으로 운영 DAC를 재실행했다. 운영 작업 `c1345ed0-552e-47d8-afc3-8650f91a80cf`는 11/11개 질문 완료, 오류 및 단계 오류 없음으로 종료했다. 이전에 실패한 `relevance-q1`도 정상 저장됐다. 최신 입력 기준 평가 상태를 확인했다. 과거 평가 기록은 보존했으며 이번 프롬프트 버전에 따른 질문 판단을 새로 저장했다.
