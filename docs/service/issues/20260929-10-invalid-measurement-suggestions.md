# ISSUE 20260929-10: 거부한 측정 제안을 AI 실패로 표시

V2.4.4 실제 재검토에서 CPCR 6명 복원, 계획표 합격률/취업률/설명회 수치의 잘못된 actual 철회를 확인했다. 다만 장비 가동률의 일부 AI 제안을 원문·복합지표 검증에서 거부한 것을 'AI 분석 재시도 필요'로 저장했다. 요청 실패와 유효하지 않은 제안을 혼동했다.

응답 배열/지표별 검토 자체가 유효하면 근거 없는 제안은 사유를 기록하고 측정값에 반영하지 않는다. 검토 완료와 검증 주의 표시를 남기며 자동 재시도 대상을 무한히 만들지 않는다. 실제 AI 요청·응답 실패는 기존 오류/재시도 처리를 유지한다. 복합 지표의 일부 단위를 확인한 경우 해당 구성요소를 인정하되 전체 달성을 주장하지 않는다.

승인 지표의 '완료'와 '유'가 동일 승인 근거인데 충돌하던 과거 값은 정규화하고, 단위 표기가 손상된 취업률 지표에서도 단위 없는 0.7을 70%와 직접 비교하지 않도록 한다. 원문이 퍼센트를 명시하지 않은 0.7을 70%로 만들어내지는 않는다.

상태: V2.4.5 운영 배포 후 4개 조합 재검토 completed. AI 재시도 필요 문구 해소, 승인 유/유 정규화 확인. 회귀 33개 통과.
