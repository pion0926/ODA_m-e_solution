# 사업 수행·증빙 신뢰도·평가 시점 분리

## 기준과 출처

사용자가 요청한 사업 수행 맥락 중심의 관대한 내부 진단을 `odame-contextual-2.0.20261008`로 분리한다. 제공 자료의 11개 질문, 55개 세부항목, 공식 점수 설명, 직접 미달·피해 검증, 40/60/80 구간은 보존한다. 다음 추출 자료를 대조했다.

- `samples/dac-scoring-20260918/extracted/참고용_ODA_평가기준_및_판정근거_설명서.txt`: 자료 부재는 성과 부재가 아니며, 미확인은 감점 대신 근거 확보율에 반영.
- 기존 `config/dac_evidence_rubric.json` 및 `docs/dac-evidence-scoring-20260918.md`: 제공 엑셀의 원자 판정 0/0.33/0.67/1과 신뢰도·상한의 적용 이력.

새 정책은 원본 엑셀의 자동점수와 동일하지 않다. 버전·라벨·안내에 내부 수정 기준임을 표시한다. 현재 자료의 진단 점수로 표시하며 공식 확정 평가로 표현하지 않는다.

## 변경

| 축 | 처리 |
| --- | --- |
| 실제 수행 | 직접 미달 0, 실제 부분 실행 0.5, 주요 범위 달성 0.75, 전체 충족 1 |
| 자료 신뢰도 | 출처·직접성·기간·추적성·독립성을 별도 계산. 낮은 출처등급만으로 성과 상태를 낮추지 않음 |
| 최고점 검증 | 4점 추가요건, 직접 검증 수준, 실제 미달·피해 상한은 유지. 신뢰도 부족의 4점 제한은 별도 사유 표시 |
| 자료 부족 | `unverified`, 평균에 0으로 넣지 않음. 충분한 근거가 없으면 점수 보류 |
| 목표 미도래 | `not_due`, 해당 원문 증빙 필수. 성과 평균·근거 확보율 분모에서 제외하고 개수 표시 |
| 시점 불명 | 미도래를 추정하지 않고 미확인. 사업 진행 중이라는 이유로 과거에 도래한 미달을 제외하지 않음 |
| 증빙 형식 | 대응표·RACI 같은 특정 양식 대신 동등한 사실을 입증하는 문서 내용을 인정 |
| 계획자료 | 설계·정합성·계획 자체의 평가에는 직접 근거로 활용. 향후 계획을 실제 성과로 바꾸지 않음 |

모든 항목에 최소 2점을 보장하지 않는다. 부분 실행만 확인된 질문은 산식상 2점 범위, 주요 범위 달성은 3점 범위가 된다. 미확인뿐인 질문은 보류, 직접 입증된 실패·도래한 정량 미달·중대한 피해는 1점이 가능하다.

## 검증

- 과거 39.8 경계 사례(상당 부분 1개+제한적 4개)는 55로 2점. 고정 2점 보정 없이 변경된 원자 값으로 계산.
- 실제 부분 실행 2점, 전부 미확인 보류, 직접 실패 및 20% 달성 1점 유지.
- 출처등급 변경 시 성과지수 동일·신뢰도 차등·4점 추가 검증 유지.
- 미도래 분모 제외, 전부 미도래 시 보류, 미도래 주장에 근거 필요.
- 화면에 잠정 진단·성과 판정 수·미확인 수·미도래 수를 구분.
- DAC 107개 테스트 및 51개 하위 사례 통과. 프런트 전체 18개 테스트 통과, 새 표시 회귀 확인.

개발 반영 완료 후 2026-10-08 사용자 요청으로 운영 V2.4.26에 API·웹을 함께 배포했다. 활성 작업 0건 확인, DB·파일 암호화 백업, API·작업자·웹 건강 상태, 외부 healthz 200 및 새 규칙/화면 스크립트 로드를 확인했다. 운영의 기존 평가 점수와 이력은 이 변경으로 덮어쓰지 않았다. 새 AI 판단과 재평가를 실행해야 새 규칙의 결과를 얻는다.
