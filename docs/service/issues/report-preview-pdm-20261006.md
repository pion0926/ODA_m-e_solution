# PDM 조판·보고서 미리보기 개선 (2026-10-06)

## 원인
- 상세 본문 charPr 85는 굵게, 92는 보통인데 용도가 반대였다. PDM 표 43/44도 뒤바뀌어 있었다.
- PDF 셀의 물리적 줄바꿈을 보고서 문단으로 유지하여 불필요한 상세 부록이 생성됐다.
- 상세 부록이 실제 페이지와 무관하게 12줄마다 계속 제목을 삽입했다.
- PDM 높이 계산은 115% 줄간격, 양식은 130%였다. SVG에 텍스트가 존재해도 셀 경계에 가려져 마지막 줄이 보이지 않았다.
- 원본 PDM 활동 셀에 바깥 번호 1.1.2와 내부 활동번호 1.1.1이 함께 존재한다. 보고서 생성 시 임의 재번호는 하지 않는다.
- 섹션 미리보기가 같은 물리 구역의 다른 표까지 조판한 후 삭제했다. 이전 요청 처리 중 새 선택/재시도가 대기했다.
- 전체 미리보기는 최신 보고서가 아닌 마지막 완료 내보내기를 열었다.

## 변경
- PDM의 논리적 목록을 유지하면서 PDF의 물리적 줄바꿈을 정리. 중복 활동 라벨 제거, 서로 다른 번호는 원문 활동번호로 명시.
- 영향·성과 / 산출·활동으로 표를 두 쪽에 배치하고 헤더 반복. 130% 줄간격과 단어 줄바꿈 여유를 높이에 반영.
- 상세 본문 보통체·제목 굵게 복원, 실제 페이지를 넘을 때만 계속 제목. 기존 상세 텍스트 해석 호환 유지.
- 선택 섹션만 조판, 요청 취소 및 최신 선택 반영, 처리 중 다시 불러오기 허용.
- 보고서 작업 화면 좌우 여백 축소. 현재 보고서 미리보기는 정상 내보내기 큐로 현재 내용을 조판.
- 전체 미리보기 읽기 전용, 보고서 작성 복귀 및 원본 HWPX 내려받기 제공.
- API·웹 rHWP 0.8.6 및 kordoc 4.18.13을 함께 승격. Windows에서 node_modules 심볼릭 링크 때문에 배포 스냅샷이 실패하는 문제도 개선.

## 검증
- 백엔드 관련 123개 + 하위 검사 3개 통과, 프런트 17개 통과.
- Playwright 16개: 데스크톱/작은 화면, 로그인, rHWP 열기/렌더/내보내기 재열기, 지연 요청 취소, 실패 재시도, 읽기 전용 이동.
- 운영 knut 문맥의 읽기 전용 사본을 개발 조판: PDM 2쪽, 마지막 활동 개최까지 시각 확인. 텍스트 존재만으로 잘림 검증을 대체하지 않음.
- 전체 기존 보고서와 신규 PDM 결합 검증: rHWP 61쪽, 실제 목차 26개 연결, PDM 15개 슬롯 및 다른 섹션 의미적 연결 검사 통과. kordoc 분석 완료.
- 개발 실제 프로젝트 브라우저: PDM 미리보기 1.0초, 1440px 화면에서 폭 맞춤 81%, 확대 동작 및 콘솔 오류 없음.
- 한컴 데스크톱에서는 직접 검증하지 않았다.
