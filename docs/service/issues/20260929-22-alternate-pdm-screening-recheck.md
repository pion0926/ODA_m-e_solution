# 대체 PDM 제외 제안의 근거 검증 실패 후 재확인 누락

신규 프로젝트에서 `사업기본자료_PDM 원안_2026-06-23_교통대.pdf`를 일반 자료로 등록했다. AI는 독립 PDM 설계본으로 분류했지만 제외 후보가 검증을 통과하지 못해 평가 자료로 보존됐다. 최초 후보의 상세 검증 정보는 저장되지 않아 어느 필드가 문제였는지는 소급 확정할 수 없다. 같은 원문을 동일 luna로 재검증했을 때는 실제 표 머리글을 연속 인용하고 등록된 최신 PDM ID를 정확히 사용하여 정상 제외 판정을 얻었다.

## 보완

- AI가 제외를 제안했으나 검증을 통과하지 못한 경우에만 한 번 재검증한다.
- 재검증에도 연속 원문·문서 역할·기준 문서 참조·신뢰도를 동일하게 검증한다. 제외 결론을 강요하지 않는다.
- 재검증 불명확/AI 실패 시 원본을 평가 자료로 보존하며 업로드를 실패시키지 않는다.
- 최초 코드·신뢰도·인용 후보와 재검증 결과를 저장하여 이후 원인 추적이 가능하다.
- 기준 버전은 v2. 명시적으로 재처리한 일반 문서는 이전 버전 사전판단을 재사용하지 않는다. 사용자의 수동 포함 결정은 유지한다.
- 현재 포함/제외가 이미 유효한 문서는 추가 AI 호출하지 않는다.

검증: 문서 제외·산출물 분류 25개 및 6개 subtest 통과. 개발/운영 새 버전의 실제 원안 재처리는 전체 흐름 기록에 추가한다.
