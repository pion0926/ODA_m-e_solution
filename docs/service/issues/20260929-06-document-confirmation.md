# ISSUE 20260929-06: 문서 재분석 확인창이 내장 브라우저에서 작동하지 않음

운영 실제 UI에서 완료 문서의 `일반 자료로 분석`을 눌러도 native confirm이 표시되지 않고 실행이 취소됐다. 데이터 변화가 없는 것을 UI와 작업 목록으로 확인했다. 재분석과 신규 평가 포함/제외의 native confirm/prompt를 화면 내 접근성 있는 dialog로 변경한다. 취소·ESC는 변경하지 않고, 확인 및 사유 입력 이후에만 요청한다. 원본과 기존 계정 권한 검증은 그대로 유지한다.

운영 V2.4.3 배포 완료. JavaScript 구문 검사·프런트 17개 검사 통과. 실적표의 취소 시 상태 유지, 확인 시 실제 재분석 큐 진입 및 AI 트레이 표시를 검증했다. 후속 일반 자료 7건도 같은 화면 흐름으로 재분석 요청했다.
