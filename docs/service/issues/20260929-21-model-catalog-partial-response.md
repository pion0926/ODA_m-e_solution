# 신규 프로젝트 모델 배정: 공급자 목록 부분 응답

## 재현

2026-09-29 운영 신규 프로젝트 `378f7335-45da-4e4a-965d-4aa4f6cdb1c5`에 knut과 같은 `openai/gpt-5.6-luna`를 배정할 때 422가 발생했다. 기본 OpenRouter 공개 모델 목록은 HTTP 200 이후 622,592바이트만 수신하고 ReadTimeout으로 끝났다. 압축 유무 변경과 30초 시간 제한에서도 실패했다. 쿼리를 달아 새로 조회한 같은 목록은 755,155바이트의 완전한 JSON을 반환했고 해당 모델의 구조화 출력 지원도 확인됐다. 정확한 상위 네트워크/캐시 계층은 확정하지 않았다.

## 수정

- 목록 조회 실패 시 같은 공식 URL에 갱신 쿼리를 붙여 1회만 재시도한다.
- 두 번 모두 실패하면 기존처럼 신규 배정을 거절한다. 가격이나 제공 여부를 추측하지 않는다.
- 실패한 목록은 1시간이 아닌 15초 후 다시 조회할 수 있다. 연속 요청은 제한한다.
- 실패 시도와 예외 유형을 기록한다. 모델, 프로젝트 원문, 인증정보는 외부로 추가 전송하지 않는다.
