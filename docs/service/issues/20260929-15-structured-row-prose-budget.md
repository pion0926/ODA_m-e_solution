# ISSUE 20260929-15: 성과표 데이터 행에 일반 문단 420자 제한 적용

실제 성과달성도 생성은 Master Instructor 지표의 여러 근거·한계를 담은 657자 데이터 행을 일반 서술 문단으로 오인하여 420자 제한으로 실패했다. 여러 셀로 나누는 `- [outputs-1-1-1]: 성과지표: ...` 행을 한 개 문단으로 검사한 원인이다. 원문이나 AI 제공자 실패가 아니다.

엄격한 지표 ID와 성과지표 필드를 가진 구조화 행만 일반 문단 길이 검사에서 분리한다. 표 내용·필드·줄바꿈·페이지 분할 검증은 기존 HWPX 파이프라인에 유지된다. 실제 긴 서술 문단과 가짜 데이터 접두어의 제한은 유지한다. 데이터나 작성 프롬프트는 바뀌지 않으며 완료된 다른 섹션과 평가를 무효화하지 않는다.

다른 섹션은 계속 생성한다. 전체 실행 종료 후 검증본을 배포하고 남은 섹션 이어쓰기 기능으로 이 섹션만 재작성한다.

검증: 구조화 행/일반 긴 문단/가짜 접두어 3가지 사례와 성과 연결·HWPX·이어쓰기 집중 회귀 104개 및 하위 사례 3개 통과. 개발 API·워커 정상 기동. 수정 전 운영과 수정 후 개발의 `prompt_manifest()` 전체가 동일함을 확인하여 기존 평가 및 완료 섹션의 입력 유효성을 유지한다.
