# ISSUE 20260929-02: 개발에서 검증한 DAC 복구 수정의 운영 미반영

운영은 9월 25일 11시 배포본에 고정되어 있어, 같은 날 오후 개발서버에서 검증한 입력 한도 오류 분류·근거 분할·완료 범위 복구·보고서 중단 처리 수정이 반영되지 않은 상태였다.

같은 오류를 운영 원본으로 재현하여 비용을 다시 발생시키기 전에, 이미 확인한 원인과 백엔드 회귀 결과를 근거로 V2.4.1에 포함해 배포했다. 이전 개발 검증은 `../dac-context-recovery-20260925.md`를 참조한다.

완료 기준은 운영에서 실제 DAC 질문 11개 완료, 보고서 전체 섹션 생성, HWPX 출력·열기 성공이다. 배포 건강 상태만으로 종료하지 않는다. 24시간 토큰/비용 한도는 임의 확대하지 않았다. 평가 전 범위 확대 정책과 보고서 입력 크기도 관찰한다.
