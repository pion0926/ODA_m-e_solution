# ISSUE 20260929-08: 다국어 승인 지표 원문·정규화 검증

첫 운영 성과 분석은 43개 문서·133개 조합을 검토하고 62개 관측치를 저장했지만 교육과정 승인 여부에서 5개 문서의 제안을 원문으로 검증하지 못해 1개 지표가 partial로 남았다. 인용문을 AI가 재작성하게 했으며, 외국어 원문에도 한국어 정규화 값이 문자 그대로 있어야 한다는 검증을 적용한 구조적 문제다. 별도 문서의 진척도 100%도 유/무 지표의 실제 값으로 제안됐다.

성과 추출도 서버 원문 ID 선택으로 변경한다. 지정된 승인 사실만 유/무로 판단하게 하고, 정확한 외국어 원문에 한국어 정규화 값 자체의 문자 일치를 요구하지 않는다. 인용 출처 검증은 유지하며 유/무 지표의 퍼센트 수치는 거부한다. 종전 완료된 정상 조합은 유지하고 실패·단위 부적합 조합만 재분석한다.

상태: V2.4.4 운영 재분석에서 최초 실패했던 승인 문서 5건의 원문 검증 실패 해소 확인. JOB CODE 승인서 등에서 원문에 연결된 유/무 결과를 저장했다. 기존 '완료'와 '유'의 표시 충돌은 이슈 10에서 추가 정규화했다.
