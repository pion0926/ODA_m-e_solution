# 신규 계정 테스트에서 발견한 화면 복구·로그아웃 접근 문제

- 새 운영 탭의 일부 정적 파일이 일시적으로 로드되지 않아 `reportModuleUnavailable is not defined`가 발생하고 접속 확인 화면에 머물렀다. 새로고침으로 로드는 복구됐지만 오류 처리 함수 자체가 외부 shell 파일에 있어 해당 파일 실패 시 안내를 표시할 수 없었다. 외부 파일 앞에 독립적인 복구 처리기를 두고 shell·review 파일 로드 실패도 처리한다. 전송 실패 자체의 네트워크 원인은 미확정이다.
- 폭 920px 이하에서는 sidebar 하단이 숨겨져 로그아웃할 수 없었다. 같은 로그아웃 동작에 연결한 상단 버튼을 좁은 화면에서만 제공한다. 개발서버 800px에서 버튼 표시와 실제 로그아웃 후 로그인 화면 복귀를 확인했고 기본 화면 크기로 복구했다.
- 검증: JS 문법 검사, 외부 shell을 로드하지 않는 독립 VM에서 복구 안내/다시 확인 버튼 표시 검증, 개발 UI 실동작. 운영 반영은 V2.4.16 배포 시 진행.
