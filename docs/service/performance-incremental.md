# 성과지표 증분 분석

성과지표 분석 미리보기와 실제 실행은 문서 단위가 아닌 문서·지표 조합 단위로 대상을 결정한다. A→1-1, B→1-2를 완료한 뒤 C→1-1과 A→1-2를 추가하면 두 신규 조합만 분석한다. 기존 완료 매핑은 유지하며 미리보기에는 유지 건수만 표시한다.

완료 이력은 PDM 원본, 지표 정의와 검증수단, 문서 ID와 파일 해시를 기준으로 최종 성과 모델에 저장한다. 모델 변경만으로 완료 조합을 재분석하지 않는다. 기존 데이터는 이전 수동 분석의 reviewed_mappings와 완료된 지표 결과로 이력을 복원한다. 성공했으나 관측값이 없는 조합도 완료로 기록한다. 실패한 조합은 다음 실행 대상으로 남으며 이전 성과값을 보존한다.

신규 문서 분석 요청에는 해당 지표의 이전 평가 정보를 함께 제공한다. 새 문서의 원문 근거가 확인된 관측값만 추가하고, 기존 근거와 함께 목표·실적을 각각 조정한다.

- 최신 여부는 업로드 시간이 아닌 원문에 명시된 측정 시점으로 판단한다.
- 최신 측정 시점이 같으면 동일 단위의 더 높은 수치를 선택한다.
- 시점이 모두 없으면 동일 단위의 높은 수치를 선택하고 시점 누락을 표시한다.
- 단위가 충돌하거나 같은 시점의 정성 값이 충돌하면 이전 값을 유지하고 검토 필요로 표시한다.

미리보기 이후 기준 성과 모델이 바뀌면 실행을 거부하고 미리보기를 다시 불러오도록 한다. 분석 완료 기록과 성과 모델은 함께 저장된다. 신규 대상이 없으면 실행할 수 없다.
