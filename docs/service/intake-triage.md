# 일반 업로드 사전 판단

일반 업로드는 원본 저장과 로컬 텍스트 추출 후, AI가 앞 10,000자·중간 3,000자·끝 3,000자를 확인해 처리 방식을 추천한다. 16,000자 이하 문서는 전체가 표본이다. 사업계획서·PDM 전용 업로드는 이 단계에 진입하지 않는다.

- `artifact`: 책·교재·매뉴얼 등 산출물 자체 또는 일부 챕터. 신뢰도 0.85 이상이면 산출물 등록을 수행한다. 기본 정보와 표본 범위의 사업계획서/PDM/DAC/보고서 관련성을 저장하며 전체 본문 분류는 하지 않는다.
- `evidence`: 실적보고서·설문·회의록·납품/배포 기록 등. 신뢰도 0.85 이상이면 기존 일반 자료 분석을 수행한다.
- `mixed`, `uncertain`, 또는 신뢰도 0.85 미만: 사용자 확인 대기 없이 산출물로 등록한다. 기존에 저장된 사전 판단에도 적용한다. 원래 판단은 `suggested_kind`에 보존한다.

자료 목록에서 산출물/일반 분석 방식을 변경할 수 있다. 처리 중이면 먼저 중지해야 한다. 완료된 자료의 변경은 확인 후 해당 문서의 자동 매핑을 초기화하고 재처리한다. 원본과 추출 텍스트는 유지한다. 작업 시작 시 최신 연결 모델을 적용한다.

산출물은 제출된 자료의 존재·내용을 등록하는 것이며 해당 사업의 제작 실적을 자동 인정하지 않는다. 일부 제출 여부와 사업 제작 여부 미확인을 명시한다. 제작 수량·배포·활용·교육 효과는 추가 증빙이 필요하다. 산출물과 일반 자료 모두 자동 매핑의 근거를 확인하지 못하면 해당 연결만 제외하고 등록은 완료한다. 모든 연결이 제외되면 미분류이며 직접 매핑할 수 있다.

기존 완료 자료는 자동 재처리하지 않는다. 대기/재요청 문서부터 적용한다. 성과 측정과 DAC 평가는 기존처럼 별도 실행한다.

검증: `test_intake_triage`, 기존 매칭·분류·기준 문서·DAC 테스트, `qa_intake_controls.py`의 격리 DB 분기·전환 테스트, `qa_foundation_upload.py`의 실제 브라우저 선택 흐름. 외부 AI 결과는 테스트 응답으로 대체한다.
