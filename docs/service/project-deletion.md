# 관리자 프로젝트 삭제

프로젝트 관리 카드의 **프로젝트 삭제**에서 삭제할 자료 수와 연결된 일반 계정 목록을 확인한다. 프로젝트명을 정확히 입력하고 **삭제 대상 확인 → 최종 확인 · 영구 삭제**를 눌러야 실행된다. 시스템 관리자 계정은 보존한다.

- 연결 계정은 다른 프로젝트 참여 여부와 함께 표시하며 계정 자체와 세션·설정·로그인 기록을 삭제한다. 다른 프로젝트의 자료는 보존하고 삭제 계정 소유 프로젝트는 실행 관리자에게 소유권을 이전한다.
- 프로젝트 삭제와 계정 삭제는 하나의 DB 트랜잭션이다. 프로젝트 외래키의 cascade로 업로드·분석·매핑·평가·보고서·번역·작업 정보를 삭제하고 토큰 사용 기록도 정리한다.
- 실행 중인 문서 처리/AI 작업이 있으면 거부한다. 실행 전 대기 중인 업로드는 함께 삭제한다. 확인 화면과 삭제 시점의 대상이 달라지면 다시 확인해야 한다.
- 원본·추출 파일, 보고서·발표자료, 부속 이미지·JSON, 진단 파일과 프로젝트별 발표자료 체크포인트를 정리한다. 저장소 밖 경로와 다른 프로젝트가 공유하는 파일은 삭제를 거부한다.
- 파일 삭제 목록을 DB 트랜잭션에 함께 저장한다. 커밋 후 파일 삭제에 실패하거나 서버가 재시작되면 작업자가 재시도하며, 완료된 목록은 제거한다. 파일 정리가 남으면 화면에 재시도 중임을 표시한다.
- 삭제된 기본 프로젝트와 데모 계정이 시작 시 다시 생성되지 않도록 최소한의 서비스 초기화 플래그를 보존한다.

검증: `tools/qa_project_deletion.py`는 임시 DB·임시 저장소와 실제 Chromium에서 권한, 확인·취소, 오래된 확인 거부, 작업 중 삭제 거부, 다른 프로젝트 보존, 파일 재시도 및 재시작을 검증한다. 실제 사용자 프로젝트는 삭제하지 않는다.
