# 평가보고서 섹션 작성 및 HWPX 내보내기 구조

## 현재 적용 범위

- `report_sections` 테이블에서 27개 섹션의 전용 프롬프트, 필수 입력, 본문, 상태, 관련 문서 ID, 생성 모델과 생성 시각을 관리한다.
- 첫 구동 시 최신 사업개요와 평가기준별 질문 분석 결과를 조합해 27개 섹션의 현재 초안을 만든다.
- 사용자는 섹션별 본문을 직접 저장하거나, 추가 지시를 붙여 OpenRouter LLM으로 선택한 섹션만 다시 생성한다.
- 생성 시 해당 섹션에 직접 배정된 문서 또는 섹션 계약의 DAC 기준과 정확한 문서 슬롯명이 모두 일치하는 자료만 사용하고, 개인정보 패턴을 비식별한 발췌문만 외부 LLM에 전달한다.
- 전체 평가가 바뀌어도 수동 편집은 자동으로 덮어쓰지 않는다. `현재 평가 반영`을 명시적으로 누를 때만 27개 초안을 다시 구성한다.

## 섹션 생성 규칙

1. `backend/report_prompts.py`의 `EDITOR_REPORT_PARTS`가 섹션 순서와 전용 프롬프트의 단일 기준이다.
2. 사업개요, 최신 평가질문별 점수·판단·한계, 앞선 섹션 최대 8개를 공통 문맥으로 사용한다.
3. `EDITOR_PART_REFERENCE_PIPELINES`의 DAC 기준과 문서 슬롯으로 섹션별 관련 문서를 선택한다.
4. 문서에 없는 사실이나 수치를 만들지 않는다. 근거가 없으면 본문 안에 `확인 필요` 또는 자료 한계로 표시한다.
5. 한 섹션 생성 실패가 다른 섹션 본문이나 작업을 손상하지 않도록 섹션 단위 상태와 오류를 저장한다.
6. 생성·AI 수정·사용자 저장의 최종 결과는 모두 `report_sections.content` 텍스트 필드에 반영하며 HWPX는 이 값을 읽는 파생 산출물이다.
7. LLM 프롬프트에는 27개 섹션별 고유 `authoring_shape`와 HWPX adapter 계약을 포함한다. 모델은 내용과 구조만 정리하며 XML·셀 주소는 생성하지 않는다.

## HWPX 내보내기 구현

```text
PostgreSQL report_sections(1~27)
        │
        ├─ 섹션 본문/표 구조 조립
        ▼
kordoc: 원본 HWPX parse → block/field 매핑 → patchHwpxBlocks 또는 fillHwpx
        │                       └─ 변경 외 ZIP/XML/서식 보존
        ├─ validateHwpx + 적용/건너뜀/검증 리포트
        ▼
rhwp: 결과 HWPX 로드 → 필드/텍스트 확인 → 브라우저 미리보기 → 사용자 저장
```

- 기존 검토 완료 슬롯 매핑으로 27개 섹션을 원본 양식의 문단·표에 반영하고, 변경하지 않은 ZIP 엔트리와 서식은 그대로 보존한다.
- 별도 `kodame-kordoc` 컨테이너가 결과물을 `validateHwpx`와 `parse`로 재검증한다. 두 검증이 모두 통과한 경우에만 다운로드를 허용한다.
- `rhwp`는 웹 미리보기, 필드 API 확인, 최종 저장 결과의 육안 검수 계층으로 사용한다. 현재 번들 자산은 `/assets/rhwp/`에 제공된다.
- 원본 양식의 문단 추가/삭제가 필요한 섹션은 단순 문자열 치환을 금지한다. 템플릿의 블록 인덱스 또는 필드명이 확정된 뒤 `patchHwpxBlocks`/Field API를 사용한다.

### 진행률과 종료 조건

- 준비 5%, 슬롯 매핑 15%, 섹션별 반영 15~70%, 패키징 75%, kordoc 검증 85%, 파일 저장 95%, 완료 100%를 `report_exports`에 저장한다.
- 브라우저는 1초마다 작업 상태를 확인하고 새로고침 후에도 최신 작업을 이어서 표시한다.
- kordoc 호출은 90초 제한이며, 브라우저 상태 확인은 최대 5분 후 종료한다. API 재시작 시 진행 중 작업은 명시적으로 실패 처리한다.
- 실패 시 진행 화면에 서버 오류를 표시하고 다시 시도할 수 있다. 완료 시 검증된 HWPX 다운로드를 자동 시작한다.

## 추가 품질 고도화

- 27개 섹션과 원본 양식 block/field 매핑의 회귀 테스트 확대
- 표지, 평가등급표, PDM, 평가매트릭스, 환류과제·교훈 표의 별도 표 매퍼
- 향후 전체 치환도 `kordoc.patchHwpxBlocks` 세션으로 이전하고 적용/건너뜀 리포트를 저장
- `rhwp`에서 페이지 수, 목차, 한글 폰트, 표 넘침을 검수한 후 다운로드 활성화
- 두 프로젝트의 MIT 라이선스 고지 포함
