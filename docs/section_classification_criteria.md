# KODAME 문서 섹션 분류 기준

- 기준 버전: `2026-08-13.1`
- 적용 범위: 자료 일괄등록 후 문서 요약·분석 및 **✦ AI 슬롯 자동 제안**
- 기본 원칙: 파일명보다 본문 근거를 우선하며, 한 문서는 관련성이 확인된 여러 섹션에 동시에 제안할 수 있다.
- 사람 검토: AI 결과는 자동 확정하지 않고 `pending` 제안으로 저장한 뒤 사용자가 승인한다.

## 분류 결과에 반드시 남기는 값

| 값 | 검토 목적 |
| --- | --- |
| 문서 유형 | 보고서, 조사자료, 회의록, 행정자료, 계획서, 통계자료, 계약·재무, 정책·전략, 기타 |
| 요약 | 문서에 명시된 사실만 사용한 5문장 이내 요약 |
| ODA 카테고리 | 사업기획, 성과관리, 조사·평가, 예산·조달, 정책·제도 등 복수 태그 |
| DAC 기준 | 적절성, 일관성, 효과성, 효율성, 영향, 지속가능성, 범분야 중 복수 선택 |
| 섹션 후보 | 섹션 번호·ID·제목, 신뢰도, 배정 이유, 근거 원문, 세부 카테고리 |
| 품질·보안 | 결측·불일치 등 품질 주의점과 공개/내부/개인/민감 등급 |

## 공통 판정 규칙

1. 본문에 직접 근거가 있을 때만 제안하며 신뢰도 45% 미만은 저장하지 않는다.
2. 같은 문서가 사업개요와 적절성, 성과 달성도와 효과성처럼 여러 목적에 실제로 쓰이면 각각 제안한다.
3. 결론·교훈·환류과제는 단일 원자료보다 종합평가 문서 또는 명시적인 결론·제언이 있는 자료를 우선한다.
4. 표지·목차·공지처럼 형식 중심 섹션은 해당 정보를 직접 제공할 때만 제안한다.
5. 신뢰도는 문서 유형의 전형성, 근거의 직접성, 섹션 활용 가능성을 종합해 산정한다.
6. 근거 원문은 사용자가 판단을 재현할 수 있는 짧은 문장으로 보존한다.

## DAC 다중 분류 예시

- 수요조사 보고서: `사업 추진배경` + `적절성`, 필요 시 `평가방법`
- PDM 및 성과지표 실적표: `PDM` + `성과 달성도` + `효과성`
- 예산집행·조달 자료: `사업개요` + `효율성`
- 운영유지관리 계획: `지속가능성`, 제도·예산 근거가 있으면 `일관성`도 가능
- 중장기 수혜자 변화 조사: `영향` + `효과성` + `성과 달성도`
- 종료평가 종합보고서: 다수 섹션 후보가 가능하나 각 후보마다 별도 직접 근거가 있어야 한다.
