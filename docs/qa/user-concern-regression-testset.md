# K-ODAME 사용자 우려사항 통합 회귀 QA TC

## 목적

사용자가 2026-08-26~2026-08-29 사이 반복적으로 우려한 로그인, 권한, 자동 배정, 대시보드, 성과관리, 종료평가, 27개 보고서 생성, HWPX 조판 문제를 하나의 릴리스 게이트로 재검증한다.

이 문서는 기존 `full-test-plan.md`, `ui-regression-testset.md`, `report-27-section-qa-checklist.md`를 대체하지 않는다. 기존 TC를 실행할 때 반드시 함께 적용하는 사용자 우려사항 회귀 묶음이다. 상세 데이터 준비와 71개 corpus 실행은 기존 풀테스트 계획을 따른다.

## 실행 원칙

- 우선순위 `P0`은 한 건이라도 실패하면 최종 보고서를 공유하지 않는다.
- 관리자 비밀번호를 포함한 실제 인증정보는 실행 시 안전한 채널로만 전달하고 저장소·스크린샷·결과 문서에는 평문으로 남기지 않는다.
- 화면 판정은 1280×720에서 실제 브라우저로 수행하고, HWPX는 방금 생성한 export를 rHWP로 다시 열어 판정한다.
- `PASS`에는 화면 캡처, API/DB 값, export id/hash 중 해당 TC가 요구하는 증적을 반드시 연결한다.
- 수정 후에는 실패 TC만 보지 않고 그 TC의 `연계 회귀` 항목까지 새 export에서 다시 실행한다.
