# 종료평가 보고서 샘플 기반 구성 기준

## 기준 샘플

`samples` 최상위의 종료평가 결과보고서 5건을 기준으로 한다.

- 파라과이 센트럴주 림삐오시 보건의료체계 형성 및 일차의료 강화사업
- 가나 글로벌보건안보구상(GHSA) 강화사업
- 방글라데시 콕스바자르 지역 소녀 및 여성 생리보건 증진 사업
- 우간다 북부 팔로리냐 남수단 난민 정착촌 WASH 및 보건 위생환경 개선사업
- 캄보디아 동북부 소외지역 모자보건 프로그램

샘플은 90~222쪽 분량이며 공통적으로 실제 목차·장표지·장/절 번호·평가매트릭스·평가기준별 본문·환류 표·첨부/참고자료 구조를 사용한다. 특정 사업의 문장이나 수치를 복사하지 않고 구성·가독성·출처 표현 방식만 참고한다.

## 본문 출처 표현

### 허용

- 본문: `4차년도 자체평가결과보고서에 따르면 ...`
- 간결 인용: `4차년도 자체평가결과보고서(2026: 13-18)`
- 표·그림 하단: `출처: 4차년도 자체평가결과보고서(2026), 13-18쪽.`
- 기관자료: `출처: 우즈베키스탄 고등교육과학혁신부(2023).`
- 같은 자료 반복 시 최초 1회 정식 명칭을 쓰고 이후에는 `4차년도 자체평가결과보고서`, `최신 PDM`처럼 사람이 읽는 단축명을 사용한다.

### 금지

- `(사업기본자료_4차년도 자체평가결과보고서_2026-06-23_교통대.pdf, pp.13-18, 효과성 평가)`
- `01_사업기본자료\...`, `/app/data/...`, 다운로드 URL 등 내부 경로
- `.pdf`, `.xlsx`, `.docx`, `.hwp`, `.zip` 확장자가 붙은 업로드 파일명
- 파일명 관리용 접두어, 밑줄, 업로드일, 사용자명, UUID, 문서 ID
- 한 문장 또는 한 문단마다 긴 괄호형 출처를 반복하여 읽기 흐름을 끊는 구성

원본 파일명과 내부 ID는 근거 추적용 metadata에 보존하되 제출 보고서 본문에는 노출하지 않는다. 전체 원자료 목록이 필요한 경우 참고문헌·첨부의 별도 목록에서 사람이 읽는 서지 형식으로 정리한다.

## 제목·번호·들여쓰기

기본 계층은 원본 HWPX 양식과 샘플 보고서의 다음 순서를 따른다.

1. 장: `제I장 평가결과 요약` 또는 양식에 지정된 `I. 평가결과 요약`
2. 절: `1. 국문 요약`
3. 항: `가. 평가 목적`
4. 세항: `(1) 문헌검토`
5. 본문 글머리: `○`
6. 하위 설명: `-`

- 같은 깊이에서 기호와 들여쓰기 값을 통일한다.
- 하위 항목은 상위보다 깊게 들여쓰고, 임의 공백이나 탭 문자로 시각적 들여쓰기를 흉내 내지 않는다.
- 제목 직후 불필요한 빈 줄을 반복하지 않고, 제목이 페이지 마지막 줄에 홀로 남지 않게 한다.
- 본문 문장은 의미 단위 문단으로 묶으며 줄 폭에 따른 자동 줄바꿈 외에 문장 중간 강제 줄바꿈을 넣지 않는다.
- 지나치게 긴 한 문단, 한 문장마다 줄바꿈, 한 글자씩 세로로 분리되는 표 셀을 허용하지 않는다.

## 목차·페이지

- 실제 보고서 장·절 제목과 순서를 그대로 사용한다.
- 점선 리더와 시작 쪽수를 정렬한다.
- 존재하지 않는 일반 목차, 제거된 평가기준, 임시 쪽수 안내를 포함하지 않는다.
- HWPX 생성 후 실제 페이지 수로 갱신하고 rhwp 미리보기에서 각 목차 항목의 시작 페이지를 대조한다.

## 표·그림

- 제목은 표·그림과 같은 페이지에 배치하고 번호와 명칭을 표시한다.
- 열 머리글, 병합, 정렬, 숫자 단위, 주석, 출처를 명확히 구분한다.
- 표 내부에 Markdown 파이프나 HTML `<br>`이 노출되지 않는다.
- 표가 페이지를 넘으면 행이 겹치거나 잘리지 않고 머리글 반복 또는 의미 단위 분할이 적용된다.
- 평가매트릭스, 성과 달성도, 기준별 점수, 작동/비작동요인, 환류과제는 샘플처럼 비교 가능한 표 구조를 우선 사용한다.
- 표·그림 하단 출처에는 사람이 읽는 문서명/기관명·연도·필요한 쪽수만 표시한다.

## 문체·근거 밀도

- 평가보고서 문체는 중립적이고 검증 가능해야 한다.
- `완벽히`, `압도적`, `모범적`, `획기적` 같은 홍보성 표현은 명확한 비교근거 없이는 사용하지 않는다.
- 핵심 판단은 `확인된 사실 → 해석 → 평가판단 → 한계/보완` 순서를 따른다.
- 수치·등급·기관명·정책명은 근거를 추적할 수 있어야 하지만 본문을 원자료 파일 목록처럼 만들지 않는다.
- 자료가 없으면 `확인되지 않음`, `자료 한계`, `추가 확인 필요`로 기술하고 추정값을 채우지 않는다.

## 최종 판정

편집 화면의 본문 내용 평가만으로 양식 PASS를 확정하지 않는다. 27개 섹션 내용 평가 후 HWPX를 저장하고, 동일 export를 rhwp 미리보기로 열어 제목 계층·들여쓰기·기호·문단·표·쪽수·출처 배치를 최종 판정한다.
