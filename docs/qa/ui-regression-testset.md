# K-ODAME UI 회귀 테스트셋

> 이 문서는 화면 중심의 빠른 회귀 테스트다. 관리자 프로젝트 준비부터 업로드·분석·지표 갱신·DAC 평가·보고서 생성까지 실행하는 종단 간 검증은 `full-test-plan.md`를 사용한다.

## 실행 원칙

- 실제 브라우저에서 로그인한 뒤 사이드 메뉴를 순서대로 클릭한다.
- 기본 데스크톱 뷰포트는 1280×720으로 한다.
- 각 화면에서 현재 프로젝트 선택 언어의 글자 깨짐, 데이터 표시, 레이아웃 압축·겹침·잘림, 가로 스크롤, 깨진 이미지, 오류 문구를 확인한다.
- 프로젝트가 복수 언어를 제공하면 `ko/en/vi/ru/uz` 중 실제 제공 언어 각각에 대해 전체 화면 흐름을 반복한다.
- 화면별 이동 후 URL hash와 활성 화면이 일치하는지 확인한다.
- 주요 화면은 현재 뷰포트 캡처로 시각 검증한다. 긴 화면의 전체 페이지 캡처는 브라우저 캡처 동작에 따라 레이아웃이 달라질 수 있으므로 판정 근거로 사용하지 않는다.
- 소스 수정 후 또는 QA 요청 시 아래 순서 전체를 재실행한다.

## 권한별 추가 확인

- 수행자: 보고서 자동작성 접근 제한과 안내 문구 확인
- 감리자: 허용 메뉴 및 보고서 접근 확인
- 발주처: 슬롯 관리와 보고서 접근 확인
- 관리자: 계정 및 권한 관리 화면 확인
